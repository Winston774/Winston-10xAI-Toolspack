# 資料、費用與素材權利

工作室只監聽本機，沒有多使用者登入或對外部署的權限隔離。勿把本機埠轉發至區網或網際網路。作品與 SQLite 保存在本機 `storage/`，但生成仍需要外部 API。

| 操作 | 會傳到哪裡 |
|---|---|
| OpenAI 連線測試 | 向 OpenAI 傳送 API 金鑰及指定模型識別碼；不送圖片或角色台詞。 |
| Agent 訂製、提示詞、生圖 | OpenAI 接收創作指示、角色描述；有參考圖的生圖任務也會上傳所選參考圖片。 |
| Fish Audio 配音 | Fish Audio 接收台詞、模型與指定音色 ID；請使用自有或經授權的音色。 |
| 進階服務 | Breeze 的遠端模式與 LongCat 的 Colab 模式各依設定傳送素材或文字；標準練習都不啟用。 |

API 依供應商方案、用量、資料政策及模型權限運作。先確認資料能否離開電腦。只使用虛構人物、合法授權的圖像及聲音；不要冒充他人，對外發布時適當標示 AI 生成內容。

學員包只保留開發專案為 Forma Studio 自製的角色示意與場景，含 Lucide 圖示與其隨附授權文件。第三方人像／服裝／姿勢圖庫及索引、匯入器、緩存圖、講師工作資料庫、個人音色、作品、Colab 產物和金鑰皆未帶入。要新增參考圖，直接在工作室上傳有權使用的素材。此教材分發不另授予第三方權利，也不以 Toolspack 根目錄授權覆蓋來源資產條款。
