# 本機問題排除

| 看到的狀況 | 先做什麼 |
|---|---|
| 找不到 `node` 或版本低於 24 | 到 [Node.js 官方下載頁](https://nodejs.org/en/download) 安裝後重開終端，再執行 `node --version`。 |
| `4317` 已被使用 | 不停止別的應用。用 PowerShell `$env:PORT='4318'`，或選另一個空閒埠，再重新啟動。開啟啟動訊息顯示的網址。 |
| 資料目錄已被使用、無法讀舊金鑰 | 關掉你自己啟動的重複實例，或將 `STUDIO_DATA_DIR` 指到另一個新資料夾。舊資料不刪；Windows 換帳戶或搬機需重新設定金鑰。 |
| OpenAI 模型找不到或權限不足 | 檢查 API 帳號、專案權限、載入模型 ID、組織驗證與額度。兩個模型可分別改；模型查詢通過後才做一次小量實測。 |
| Fish Audio 沒出現 WAV | 確認點了下方區塊的「儲存設定」，角色的配音服務選 Fish Audio，模型與音色 ID 在你的帳號可用。再看作品庫失敗原因及 Fish 後台額度。 |
| 服裝、姿勢庫是空的 | 教材刻意不附第三方素材。從角色編輯器開啟素材選擇器，按「上傳自備圖片」，或純文字描述。 |
| 影片按鈕提示需啟用 LongCat | 只完成本週圖片及 WAV 練習即可。影片需要另設 LongCat CLI／Colab A100 並另行同意費用，兩組金鑰無法替代這些依賴。 |
| 供應商逾時、任務失敗或準備重試 | 先查作品庫和供應商端的狀態與費用，確定沒有可續取的任務再重送。報錯時只交付步驟與遮蔽後的訊息，不附 SQLite、完整日誌或任何金鑰。 |
