# Forma Studio｜本機 Codex 操作清單

這份文件只在學員明確要求啟動時使用。操作範圍限解壓後的 Forma Studio。安裝系統程式、持久化設定、使用任何付費供應商或啟動 GPU 前，分別向使用者確認。

1. 讀同層 [README](README.md)，確認 `package.json` 的名稱與 `server/index.mjs` 存在。執行 `node --version`；未達 24 時停下告知，不自行安裝。基本執行不需要 npm 套件、Python、GPU 或 WSL。
2. 用 `npm run validate`（Windows 可用 `npm.cmd run validate`）做離線分發檢查。啟動前確認 `4317` 沒被其他服務占用。若占用，為本次程序選另一個空閒埠，例如 PowerShell `$env:PORT='4318'`；不要終止其他程序。若本資料夾已有 `storage/`，保留它並讓使用者決定是否繼續；要另開測試可將 `STUDIO_DATA_DIR` 指向一個已確認的全新私人資料夾。
3. 在專案根目錄開啟工作室：`node server/index.mjs`。核對啟動訊息只顯示 `127.0.0.1`，讀取 `/api/health` 預期 `{"ok":true}`，打開首頁確認可看到角色範本。無需記錄、輸出或搬移任何設定資料庫。
4. 打開 `<本機網址>/#settings`，讓使用者在介面中自行貼上兩組金鑰並儲存。畫面交還前不讀表單值、不截圖、不讀取 `storage/` 或記錄設定請求。程式從自己的本機設定存取金鑰；不用建立 `.env`。即使發現環境變數或憑證，也不能擅自沿用。若使用者另外請 Codex 取得新 OpenAI 金鑰，交由當前 Codex 的安全憑證流程處理；本包不含帳戶或金鑰。
5. 未獲授權前，維持 LongCat 關閉、Breeze 欄位留白。使用者要實測時，先說明會傳哪些資料給哪一家服務、可能費用及驗收條件，再由使用者逐項同意或手動送出。先用虛構人物與無敏感資料的短台詞。
6. 回報本機網址、啟動是否成功、使用者尚待填寫的項目，以及如何在本次啟動的終端按 `Ctrl+C` 停止。避免反覆送出逾時或失敗工作；先看作品庫與供應商後台，確認有無計費或背景任務。
