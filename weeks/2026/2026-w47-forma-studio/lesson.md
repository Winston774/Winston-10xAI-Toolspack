# 60 分鐘｜做一個可重複使用的虛構角色

這次用同一個角色完成造型設定、定裝照、配音。基本練習不配置 Colab 或安裝模型。

1. **10 分鐘｜啟動**：用本機 Codex 讀 [啟動任務](starter/給-Codex-的啟動任務.md)。打開首頁，確認已有五款虛構範本。從 Sora 另存成自己的角色。
2. **15 分鐘｜造型**：填寫年齡、職業、個性及外型；設定「木質咖啡館、半身、窗邊自然光」。有授權的自備服裝或姿勢圖才上傳，也可以用文字描述。儲存後重新進入角色，確認欄位在。
3. **20 分鐘｜拍一張照**：先讓 OpenAI 模型查詢通過。自己確認費用後，在攝影棚生成一張定裝照。成功後到作品庫查看圖片，將它套用回角色或另存。
4. **15 分鐘｜配一段音**：在「聲音與表演」切成 Fish Audio，輸入「大家好，今天我在窗邊介紹一杯手沖咖啡。」只使用你有權使用的音色。確認費用後送出一次，回作品庫播放與下載 WAV。

**通過標準：** 同一角色重新載入後仍保留設定，作品庫中有一張與角色關聯的可開啟照片、一段可播放 WAV。各記下用了哪個模型、哪些資料送到供應商及你對成果的一項調整建議。不要上傳證明畫面裡的 API 金鑰、私人資料庫或未授權素材。

**無金鑰的練習：** 完成步驟 1、2 並瀏覽拍攝與配音設定，記錄哪項需帳號。只評估本機啟動及角色設定，生圖與配音標記為待驗。失敗先看[排除步驟](docs/troubleshooting.md)，避免重複送出付費請求。
