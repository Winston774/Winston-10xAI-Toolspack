# 已知限制與 Preview 邊界

- Agent 的內容理解依賴字幕與能取得的視聽證據；ASR 專名、否定、數字與說話者可能有誤。
- 八項分數是編輯量尺，未經重要段落召回率、準確率、流量或觀眾偏好校準。
- 核心工具接受本機檔案，不含 YouTube 下載器。無字稿時只能準備媒體及列出缺口，不能編造引用。
- 固定取景不含人臉追蹤、多機位切換、動態縮放或分割視窗。多人、移動與圖表建議先用 pad。
- SRT 跨切點時會保留完整 cue 文字，只裁時間；須回聽修正或重找切點。
- 預設分別輸出各段影片。原對話的五段合輯、中英翻譯及雙語字幕由該次專用腳本另行完成，未納入此版本的通用 CLI。
- 選配 faster-whisper 入口採 CPU/int8；模型名稱可能下載檔案。本次發布驗證未重跑此 ASR 入口或下載模型。
- FFprobe 驗證涵蓋尺寸、編碼、時長與音軌等結構；無法保證音畫感知同步、中文字幕字形、內容完整或剪輯美感。
- 來源的真實訪談案例與合輯仍有未完成人工連續聽校的項目。本次沒有重新觀看或聆聽該影片。
- 本次媒體測試在 Windows 執行；macOS、Linux、其他 Python/FFmpeg 組合及全新學員帳號安裝尚未驗收。
- 不含自動發布、內容權利確認、HDR 色彩管理或商用素材授權。工具預期處理受信任的本機素材；不作為不受信任媒體的隔離沙箱。

因此本週維持 v0.1.0 Preview；可用於學習與審閱稿，正式發布前需人工核對。
