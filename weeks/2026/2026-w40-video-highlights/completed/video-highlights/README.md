# Video Highlights

把訪談、Podcast、課程與直播回放，剪成多個有評分的精華片段。

由 agent 讀完整份帶時間逐字稿，再查看候選區段的畫面與聲音；本機工具依片長、完整性與主題多樣性選段，輸出直式／橫式 MP4、字幕及理由報告。

## 給學員的三步驟

1. 解壓縮後，將整個 `video-highlights` 資料夾放進使用平台的技能目錄。Codex 的預設目錄為 `~/.codex/skills/`；Windows 通常是 `%USERPROFILE%\.codex\skills\`。保留 scripts、references、agents 等子目錄，重新開啟對話使技能被發現。
2. 準備 Python 3.10+ 與 FFmpeg/FFprobe，先請 agent 執行此技能的 doctor。已有 SRT 最省資源；沒有字幕可選配本機 faster-whisper。完整步驟見 [操作說明](references/usage.md)。
3. 將影片路徑交給 agent，直接貼上以下需求。

```text
使用 $video-highlights，幫我把這支訪談剪成 5 個重點片段，
每段 45–75 秒，同時提供直式和橫式影片。
我要每段的總分、分項評分、入選理由、原片時間和字幕。
影片：<本機影片路徑>
字幕：<本機 SRT 路徑；沒有可省略>
輸出：<工作目錄>
```

也可以指定「重點放在創業方法」、「最多 60 秒」、「只要直式」、「優先有具體案例的回答」。規格未指定時採最多 5 段、30–90 秒、直橫兩版。

## 你會拿到什麼

- 每段 MP4 與 SRT；可選燒入字幕。
- 八項編輯量尺合成的 0–100 分，附理由及獨立的信心等級。
- 全片主題地圖、來源引文、候選去重與未入選原因。
- 可修改再匯出的 JSON 計畫，以及實際尺寸、時長、音軌檢查報告。

影片在本機剪輯，核心工具無額外模型 API。內容判斷由目前執行技能的 agent 完成，其模型使用方式取決於你使用的平台。原片缺字幕、工具無法聆聽或素材有疑義時，交付會清楚標示草稿／待確認，不把未檢視內容寫成已確認。

固定取景裁切適用於位置穩定的主體。多人移動或圖表較多的畫面，預設保留全幅並補邊。技能未包含動態人臉追蹤、UI、發布帳號或自動上傳功能。

進階規則見 [SKILL.md](SKILL.md)、[評分規範](references/rubric.md)；本次可驗證範圍見 [VALIDATION.md](VALIDATION.md)。
