# Stylebase

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- 主要使用者是收集設計參考的個人設計工作者，在 Windows 本機整理網頁、UI、產品與品牌設計截圖。
- 主要工作是把散落的視覺參考轉成日後設計實作時可搜尋、可比較、可重用的設計知識。
- 假設：第一版是單機單人使用，不需要帳號、多人同步或雲端分享；此假設是在選擇頁兩次等待未收到回覆後，依原始需求採用。

## Product Purpose

Stylebase 是一套本地視覺參考資料庫。使用者把圖片放進指定資料夾或透過介面匯入後，系統會先建立索引；使用者按下「送交 Codex」後，任務進入分析佇列，由 Codex 內建 AI Agent 辨識內容、分類設計領域、描述視覺風格，並生成可直接用於後續設計或影像模型的提示詞。

成功代表使用者能在幾秒內從大量截圖中找到適合目前任務的參考，理解它為什麼有效，並帶走可實作的設計語彙與提示詞。

## Positioning

Stylebase 不只保存圖片，而是把每張截圖轉譯成「可搜尋的設計決策」：視覺分類、構圖、色彩、字體、元件、互動線索、適用情境與生成提示詞都與原圖保存在同一筆本地紀錄中。

## Operating Context

- 圖片來源包含網頁設計截圖、UI 設計、產品設計、品牌識別與視覺概念圖。
- 主要入口是監看的本地 `inbox` 資料夾與網頁匯入介面。
- 使用者會以搜尋、篩選、標籤、收藏、相似風格與分析狀態瀏覽素材。
- 每筆素材需要保留選填的來源網址、作者／工作室、收集日期與授權／使用備註，避免把靈感誤認成可直接複製的資產。

## Capabilities and Constraints

- 本地 SQLite 是資料真相來源；原圖與縮圖保留在專案資料目錄。
- 支援 JPG、JPEG、PNG、WebP、GIF；第一版不處理影片、PDF 或雲端同步。
- 匯入時以檔案雜湊去重，並保留分析版本、模型來源、錯誤與重試狀態。
- 圖片分析使用這台電腦已登入的 Codex 內建 AI Agent；不要求另外安裝 Ollama，也不在 Stylebase 中保存 API 金鑰。
- 分析必須由使用者在介面按下「送交 Codex」後才啟動。匯入本身不會自動把圖片送入模型。
- 每次任務以唯讀 sandbox、單張圖片與嚴格 JSON Schema 執行；同一時間只跑一個 Agent 工作。
- Codex Agent 暫時不可用時，匯入、手動編輯、搜尋與瀏覽仍可正常使用；工作會停在可理解且可重試的狀態。
- 第一版提供手動掃描與單次資料夾匯入，不假設背景常駐服務永遠開啟。

## Evidence on Hand

- 使用者目前提供了產品需求與目標路徑，但尚未提供真實素材圖片、既有分類法、品牌識別或分析結果。
- 展示內容必須標示為示範資料；不得捏造客戶、成效、授權狀態或模型準確率。

## Product Principles

1. 原圖優先：介面退後，讓視覺參考始終是主角。
2. 本機可控：未經主動設定，不把圖片送往外部服務。
3. 分析可追溯：模型、時間、版本、提示詞與失敗原因都能被看見。
4. 人能修正：AI 分類與描述是可編輯的起點，不是不可逆的結論。
5. 為實作而整理：每筆分析都要回答「這個參考可以如何轉成設計決策」。

## Accessibility & Inclusion

- 鍵盤可完成主要操作，所有互動控制具備可見焦點。
- 圖片分析描述可作為替代文字的起點，但需清楚標示為 AI 產生並允許人工修改。
- 不只依靠顏色表示分析狀態、收藏或錯誤。
