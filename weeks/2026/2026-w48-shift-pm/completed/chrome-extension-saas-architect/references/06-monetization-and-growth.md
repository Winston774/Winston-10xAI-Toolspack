# 成本與毛利試算、收費定價設計與 GTM 成長指南

> **給 Agent 的核心任務**：這份文件不是固定數字範本，而是一套**幫創辦人算清楚帳、定對價格、設計出低獲客成本 GTM 引擎的通用決策工具**。請帶創辦人把他們自己的產品數字代進去算一遍！

## 一、成本結構與單位經濟（Unit Economics）試算公式

先請創辦人估計「一位重度付費用戶一個月會花掉你多少成本」，再套用以下通用公式決定價格底線：

### 1. 拆解三類成本
- **固定月費（Fixed Infra）**：例如 Supabase Pro（\$25）＋ Workers Paid（\$5）＋ 網域分攤（~\$1）≈ **\$31/月**（Pattern 1 甚至可為 \$0–\$5/月）。這部分只需少量付費用戶即可打平（Break-even）。
- **金流手續費（Payment / MoR Fee）**：以 Paddle `5% + \$0.50` 為例（或依實際金流費率代入）。
- **單用戶變動成本（Variable Upstream Cost）**：
  - Pattern 1（純本地）：**\$0**
  - Pattern 2（雲端同步）：極低（儲存＋讀寫通常 < \$0.05/人/月）
  - Pattern 3（呼叫付費 API）：`單次呼叫平均成本 × 方案內含最高次數（或時數）`
  - Pattern 4（含共享快取）：`Pattern 3 成本 × (1 - 預估快取命中率)`

### 2. 兩條必算毛利紅線
```text
最壞毛利率（Worst-Case Margin，假設用戶把配額 100% 用光且 0% 快取命中）：
  = (方案售價 - 金流手續費 - 滿載變動成本) / 方案售價
  ★ 健康底線：≥ 55%（確保就算遇到最極端重度用戶也不會虧錢！）

混合毛利率（Blended Margin，考量真實平均使用率 40–60% ＋ 快取命中）：
  ★ 健康目標：Pattern 1–2 達 85–95%；Pattern 3–4 達 75–90%
```

### 3. 金流手續費佔比優化（極關鍵！）
任何按筆收取固定費（如 `+ \$0.50`）的金流，**客單價越低、手續費佔比越痛**：
- 賣 **\$5** 單筆：手續費 \$0.75 = **15.0%**（太貴！）
- 賣 **\$12** 單筆：手續費 \$1.10 = **9.2%**
- 賣 **\$60–\$70 年繳**：手續費約 \$3.50–\$4.00 = **5.7% 左右**

**通用商業設計對策**：
1. **定價頁預設選中「年繳方案」**（提供 20–30% 折扣誘因）：手續費佔比腰斬、立刻回籠一整年預收現金流、且年流失率遠低於月繳！
2. 若提供一次性加購包或低額方案，定價盡量避開 \$5 以下，並將較高面額標示為「最划算推薦（Best Value）」。

## 二、如何幫創辦人決定最適合的收費模式？

| 方案設計模式 | 最適合的產品 | 優勢與心理學設計 | 實作注意事項 |
| :--- | :--- | :--- | :--- |
| **1. 一次性買斷（One-time / Lifetime）** | Pattern 1 純本地工具、低後續維護成本 | 決策門檻最低、快速收回現金流 | 絕不可用在有持續上游 API 成本的 Pattern 3/4，否則老用戶會長期吃垮毛利！ |
| **2. 功能分級訂閱（Freemium + Pro 月／年繳）** | Pattern 1 / 2（變動成本趨近 \$0） | 免費版靠日常高頻習慣留客，付費解鎖進階匯出／無限筆數／雲端同步／進階工作流 | 免費版要「真的能解決一次小痛點」，不要做成不能用的殘廢試用版。 |
| **3. 訂閱配額 ＋ 永不過期加購包（Hybrid Credits）** | Pattern 3 / 4（每次使用有變動 API 成本） | 月訂閱建立穩定 MRR；永不過期加購包消除輕度用戶「怕這個月用不完浪費」的抗拒！ | 1. 資料庫用整數最小計量單位（如 credits / 秒數），絕不用浮點數；<br>2. **一律優先消耗會過期的月配額**，用盡才扣永不過期加購包；<br>3. 全站與外掛 Popup 統一顯示「剩餘」額度與清楚的明細來源桶。 |
| **4. 免費體驗設計（Free Trial）** | 全模式 | 讓用戶「先看到魔法再掏卡」大幅拉高註冊轉化率 | 建議設為**用量上限型一次性體驗**（且須 Email 驗證＋Turnstile 防濫刷），比純時間限制（7 天免費）更能控制最壞獲客成本（CAC）。 |

> **共享快取作為毛利倍增器（Pattern 4 專用）**：若多位用戶會反覆查詢同一份公開資源，可透過私有 Cloudflare R2（\$0 出站費）快取處理結果，命中用戶享有「0 秒即出」體驗同時維持正常計費、你方上游成本降為 \$0——快取命中率每提升 25%，整體毛利就能跳升一階。前提是嚴格遵守公開資源驗證、用戶選擇退出權（Opt-out）、寫回簽章與下架機制。

## 三、通用 GTM（Go-To-Market）上市與成長系統設計

不要等上線那天才想「怎麼賣」——從 M3 開始就同步把成長引擎寫進產品與官網裡：

### Step 1：鎖定第一批最願意付費的受眾（Beachhead Positioning）
幫創辦人拆出兩層受眾：
- **P0 主力付費群**：痛點最痛、時間最貴、最有預算的人（例如用你的外掛直接幫他省時間、賺錢、或提升工作表現的專業工作者／創作者／賣家）。定價與官網主文案一律優先寫給 P0 看！
- **P1 社群擴散引擎**：基數大、喜歡分享酷工具的次文化或垂直社群，用來放大自然流量、搜尋聲量與口碑截圖。

### Step 2：打造「60 秒首分鐘魔法體驗」（Time-to-First-Value < 60s）
Chrome 外掛 60% 以上流失發生在「裝完不知道怎麼用」：
1. 安裝完成由 `chrome.runtime.onInstalled` 自動開啟對應語系的 `/welcome` 引導頁；
2. 1 鍵登入並自動完成 Web ↔ 外掛 PKCE 連線（頁首與控制台同步顯示已連線綠燈）；
3. `/welcome` 直接提供一個「免準備、點開就能馬上試用」的示範頁面或快速任務按鈕，讓新用戶裝完不到 1 分鐘就親眼見證核心價值。

### Step 3：建立免費且會複利成長的兩大自然流量池
1. **高意圖 SEO 著陸頁矩陣（Astro 靜態生成，CWV 95+）**：
   - **3–4 個核心場景頁（Use Cases）**：針對你受眾在 Google 真實搜尋的痛點長尾詞撰寫專頁；
   - **2–3 個競品比較頁（Comparisons）**：客觀對比「你的產品 vs 市場前 3 大已知工具」（直接截流已有付費意願的精準搜尋者）；
   - **技術 SEO 必備**：多語 `hreflang`、Canonical、乾淨 Sitemap（排除 app 路由）、OG 分享圖與 JSON-LD（`SoftwareApplication`、`FAQPage`、`Offer`）。
2. **Chrome Web Store ASO ＋ 溫和五星評價飛輪**：
   - 商店標題：`品牌名 — 核心高搜尋量關鍵字`；補齊多語 `_locales`（英文為全球預設＋母語，預留日／韓擴充）。
   - **評價邀請時機**：絕不在首次安裝就跳出討評分！設定條件（例如成功完成 ≥ 3 次核心任務且無錯誤），才在 Popup 溫和顯示一次評分邀請，點過或關閉即永久隱藏。

### Step 4：隱私優先的北極星漏斗與 4 封高回報留存信件
- **漏斗指標（Server-side PostHog）**：
  `Install → Verified Signup → First Core Value → Low-Quota / Trial-Ending → Paywall Hit → First Paid Conversion → Day-30 Retention → Gross Margin`
- **4 封必設自動信件（Resend）**：
  1. **Welcome 歡迎信**：驗證成功即寄，附快捷鍵與 1 步驟上手提示；
  2. **額度剩 20% / 試用將到期提醒**：單次去重，溫和提醒並附方案比較；
  3. **觸發付費牆跟進信**：清楚呈現年繳優惠與無壓力方案；
  4. **付款失敗挽留信（Dunning）**：收到 `past_due` 時立刻附上更新卡片入口，直接救回非自願流失。

### Step 5：低成本冷啟動爆破順序（Launch Week）
1. **先用 CWS Unlisted 找 30–50 位種子用戶封測**（社群學員／垂直論壇／早期候補名單）：修完真實現場 Bug、收集真實推薦語與第一批自然五星評價。
2. **準備 3 支 15–30 秒直式 Before/After 對比短影音**：前 3 秒直接呈現痛點 vs 開啟外掛瞬間解決的視覺反差（零廢話教學感）。
3. **轉 Public 同步多點發布**：Product Hunt、Hacker News（Show HN）、Reddit 對應垂直版塊、X / Threads、YouTube Shorts / Reels，並鎖定與你產品最相關的創作者或社團做分潤／互惠推廣。
