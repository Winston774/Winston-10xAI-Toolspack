# W48 驗證範圍

- 技能以文件、參考與範本運作，沒有安裝腳本或強制工具依賴。`shift-pm` 為 Codex 呼叫名稱；保留整個目錄可讓參考連結解析。
- 依 README 從 ZIP 解壓，將技能資料夾放到隔離測試專案的 `.agents/skills/`。以本機 Codex 技能清單重新掃描，確認 `shift-pm` 為啟用的 repo 級技能，且路徑命中測試副本。此步驟未呼叫模型或修改既有技能安裝。
- 以本週教材的文件、ZIP 檔案名單、解壓文字與 Git 變更範圍為檢查對象。檢查 Skill frontmatter、UI metadata、相對引用、JSON、UTF-8、常見秘密格式及私用識別，公開文件不匯入內部案例或部署指令。
- 獨立 Agent 以虛構案例進行唯讀試跑：辨識「本機 MVP → 小規模封測」，保留本機模式、延後登入／同步／金流，交付一張含乾淨環境、正常與失敗驗收和停止條件的工單，將未執行的實機檢查保留待驗。這是指令行為試跑，未對任何 Chrome 外掛執行安裝、真實上架、付費或外部部署，也不代表商店審核結果。
