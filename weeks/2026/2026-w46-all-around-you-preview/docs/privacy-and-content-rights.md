# 隱私、外部傳輸與第三方權利

本週提供原樣可攜式程式 ZIP；教材 ZIP 與 Git 歷史僅放指南、雜湊及下載資訊。沒有加入個人 settings/status、裝置映射、校正報告或錄音。範例 profile 全為佔位值，不可直接套用。

程式會讀取音訊裝置、路由音訊及按操作使用麥克風。來源手冊記錄麥克風分析在本機記憶體進行、不存錄音、不上傳；本次沒有執行錄音、路由或動態網路監測。設定與報告可含裝置 ID／名稱、路徑、PID、時間及量測數值，留在學員電腦，公開前先檢查。

主程式未簽章；不能將隨包雜湊清單當作獨立身分證明。請從明確的 W46 Release 取得檔案並核對外部 SHA-256；若安全政策阻擋，不停用防護或驅動簽章檢查。
