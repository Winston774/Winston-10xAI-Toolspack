------------------------------------------------------------------------
ABOUT THE SOFTWARE
------------------------------------------------------------------------
Easy Surround PRO is an ultra-low latency, professional multi-channel 
audio DSP routing engine. It is designed specifically to bridge separate 
physical audio outputs (such as front AUX speakers and rear USB-C/Bluetooth 
speakers) to create a unified, high-fidelity spatial surround sound field.

------------------------------------------------------------------------
CORE PROCESSING FEATURES
------------------------------------------------------------------------
- Real-Time Loopback Capture: Bit-perfect capture of Windows system audio 
  using a high-performance, low-latency WASAPI loopback engine.
- Dual-Device Routing: Simultaneously routes front channels to one audio 
  interface and rear channels to a separate physical output device.
- Microsecond Delay Compensation: Allows precise phase-alignment to 
  compensate for hardware and distance latency.
- Stable Name Resolution: Saves your configuration using physical hardware 
  device names, preventing channel swaps on reboot.
- Inactive Stream Watchdog: Automatic 2.0s heartbeat thread control to 
  detect and self-heal stream freezes.

------------------------------------------------------------------------
SUPPORTED AUDIO FORMATS & SPECIFICATIONS
------------------------------------------------------------------------
- True Discrete 7.1 Surround (FL, FR, C, LFE, RL, RR, SL, SR)
- True Discrete 5.1 Surround (FL, FR, C, LFE, RL, RR)
- Smart Peak-Based Fallback: Automatically falls back to high-fidelity 
  matrix upmixing for downmixed multi-channel signals, and silences rear 
  speakers for standard stereo streams (e.g., Spotify).

------------------------------------------------------------------------
TECHNICAL DSP DETAILS
------------------------------------------------------------------------
- Sampling Rates: 44.1 kHz, 48.0 kHz, 96.0 kHz
- Resolution: 16-bit PCM / 24-bit Studio Depth
- Loopback Mode: WASAPI Shared Mode Capture
- Output Drivers: Low-latency PortAudio MME
- Priority Class: HIGH_PRIORITY_CLASS
