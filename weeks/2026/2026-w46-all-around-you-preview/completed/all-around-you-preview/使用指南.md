# All Around You Preview 版 · 使用指南

這是 Windows x64 預覽版；各種新電腦、藍牙組合及長時間同步仍需現場驗收。由 agent 協助設定時，請先閱讀同資料夾的 AGENT_INSTALL.md。

解壓縮完整 ZIP，執行 `AllAroundYouPreview.exe`。旁邊的 `_internal` 資料夾須留在同一處。已附 Python 執行環境，無須另裝 Python、Node.js 或 Electron。

## 在 Windows 選一個裝置就播放

第一次設定完成後，Windows 的音訊會經過這條路徑。

Windows／播放器 → CABLE Input → All Around You Preview常駐程式 → 左前、右前、左後、右後所選喇叭，套用四個位置各自儲存的延遲。

1. 讓要使用的喇叭在 Windows 顯示已連線。可選四個不同裝置，也可讓一組立體聲喇叭負責兩個位置。
2. 若尚未安裝 VB-CABLE，在程式下方的「Windows 環繞輸出」按「安裝虛擬音訊端點」。Windows 可能顯示管理員提示。官方建議安裝後重新啟動 Windows，程式不會替你重開機。
3. 按「設定為 4.0 環繞入口」。程式會將標準 VB-CABLE Speaker 端點設成 **4 聲道、48 kHz**，並自動選為來源。Windows 裝置名稱保留 **CABLE Input (VB-Audio Virtual Cable)**。請勿選 CABLE In 16ch 或錄音端的 CABLE Output。
4. 分別選好左前方 FL、右前方 FR、左後方 RL、右後方 RR 的裝置，確認四個延遲值。勾選「開啟程式時自動載入環繞，裝置重連後恢復」及「登入 Windows 時啟動並留在通知區」。聲道配置使用「自動」。
5. 在程式按「開始」，確認顯示播放中、路由已啟動。再到 Windows「設定 → 系統 → 音效 → 輸出」選 **CABLE Input (VB-Audio Virtual Cable)**。也可以只在指定播放器中選這個端點。若路由尚未啟動，先處理程式顯示的原因，避免切換後無聲。

程式需要保持執行。按視窗右上角 X 會縮到通知區；雙擊通知區圖示或再次執行 EXE 可開啟設定。通知區右鍵「停止並退出」會停止路由。若此時 Windows 仍選 CABLE Input，會暫時沒有聲音，請改選實體喇叭或重新開啟本程式。

藍牙裝置離線時，程式保留原本的選擇並等待重連，不會自行換成另一組喇叭。按「停止」會暫停本次執行的自動恢復；按「開始」可繼續。

## 四個位置怎麼選

每個位置都有自己的喇叭選單及 0–500 ms 延遲，可輸入小數。停止播放後即可更改。

| 你使用的裝置 | 選擇方式 | 實際輸出 |
| --- | --- | --- |
| 一組 Realtek 前方立體聲喇叭 | FL、FR 都選 Realtek | FL 到該裝置左聲道，FR 到右聲道 |
| 兩顆不同後方喇叭 | RL 選第一顆，RR 選第二顆 | 每顆只收到它的位置內容 |
| 四顆不同喇叭 | 四個位置各選一個裝置 | 四個獨立位置各自輸出 |

一個裝置只負責一個位置時，該位置的單聲道內容會送到裝置左右兩聲道，因此單顆藍牙喇叭也能使用。原生單聲道裝置使用單聲道輸出。一個立體聲裝置最多分配兩個位置；介面會顯示各位置實際使用該裝置的左或右聲道，同裝置只開一條串流。

若一顆 JBL 同時選為 RL 和 RR，它仍只有一個實體位置。想分出左後與右後，請連接兩顆喇叭，並分別選取兩個 Windows 端點。若 Windows 只看見一個合併後的裝置，程式無法把它拆成兩個獨立端點。

新版會自動把舊前方設定帶到 FL／FR，舊後方設定帶到 RL／RR，保留模式、音量與延遲。每個四位置裝置組合保存自己的延遲；新組合從 0 開始，請重新量測，切回已保存組合會載入該組合的補償。只選取裝置不會自行開啟麥克風。

## 播放模式與後方音量

在裝置設定下方選擇「播放模式」。切換模式時，先按「停止」，選好模式後再按「開始」。

| 模式 | 聽到的效果 | 適用情境 |
| --- | --- | --- |
| 全喇叭立體聲 | 左聲道同時送到前左與後左，右聲道送到前右與後右 | 音樂、YouTube、希望前後都播放 |
| 模擬環繞 | 前方保留主要聲音，後方播放較弱的環境感；中央人聲在後方會減弱 | 想增加空間感的立體聲節目 |
| 原音分流 | 按原本的聲道位置分送；立體聲來源只播放前方 | 原生 4.0／5.1／7.1 電影、遊戲及四聲道測試檔 |

「後方音量」可在播放中拖動，範圍 0–100%。0% 只靜音後方，100% 使用該模式的完整後方音量。滑桿同時調整 RL／RR，不改前方音量；Windows 系統音量仍控制四個位置。設定會保存，重開程式與裝置重連後繼續使用。日常使用可先從 50% 開始。

「聲道配置」描述來源端點的 PCM 格式，保留「自動」即可。即使音樂只有兩聲道，CABLE Input 仍可提供四聲道容器；不需要把配置改成「立體聲」。

全喇叭立體聲及模擬環繞都會先把多聲道內容混成立體聲，再套用效果。若要保留電影的獨立後方方位，請切回原音分流。程式不會依後方短暫安靜自行切換模式。

模擬環繞屬於環境音效果，無法還原片源沒有記錄的獨立環繞資訊。這版對左右差異做 180–7000 Hz 帶限、少量混入原音，後方加 12 ms 的環境效果延遲。這 12 ms 與藍牙延遲補償分開處理，不會改寫校正數值。

後方差分使用同相成分，避免單顆 JBL 合併左右後完全抵消；單顆喇叭依然無法在空間上分出後左與後右。左右相同的人聲在後方會明顯降低，偏左、偏右或帶混響的人聲仍可能進入後方。

## 檢查四個方位與校正

測試與麥克風校正會暫時略過播放效果及後方音量設定，使用原本的低音量測試訊號。內建 4.0 巡迴測試也固定使用原音分流。

停止路由後，可先使用 FL、FR、RL、RR 測試按鈕確認前左、前右、後左、後右。內建「4.0 聲道巡迴測試」也能循環測試，但常駐自動播放不會使用內建測試音。

選「原音分流」並把後方音量設到可聽見的程度後，也可讓路由保持執行，用支援多聲道 PCM 的播放器開啟隨附的 `4.0-前左前右後左後右.wav`。這是 8 秒的四聲道測試檔，依序測四個方位，每隔兩秒換一個方位。播放器輸出請選 CABLE Input 並依循系統的四聲道配置。

把獨立 USB 或電腦麥克風放在座位耳朵高度，停止其他聲音，再按「測量偏移」。四個位置會逐一發出短探測音，約需 25 秒。程式分別量測四個到達時間，將較早到達的位置延後，與最慢的位置對齊，四個補償值會一起保存。

量測時暫時略過既有延遲、播放效果及後方音量。按「驗證目前補償」則使用四個已設定的延遲，顯示各位置相對左前方的差距，以及最大到達差；驗證不會改寫設定。任一位置辨識失敗、時間不穩定或超出 500 ms，整次量測會拒絕套用。錄音僅在本機記憶體分析。

補償範圍每個位置為 0–500 ms。藍牙重新連線、喚醒、移動座位或更換任一顆喇叭後，建議重新驗證。程式會載入先前數值，無法據此保證藍牙內部延遲完全相同。校正完成後按「開始」繼續路由。

## 片源與音量

- 需要片源提供環繞聲道，才會有獨立後方內容。一般 YouTube 與立體聲音樂可選「全喇叭立體聲」或「模擬環繞」增加後方播放。
- 電影／遊戲應使用多聲道 PCM，關閉 Dolby/DTS 位元流直通。建議播放器依循 Windows 的四聲道配置。不同播放器對 5.1／7.1 轉成四聲道的方式可能不同。
- 若選其他 5.1／7.1 虛擬來源，本程式仍支援原生 5.1／7.1 分流及中置、LFE、側後環繞混音。手動選的配置必須與實際來源聲道數吻合。
- 先把實體喇叭音量調到舒適的小音量。不同喇叭的音色及音量差異仍需個別調整。
- 本程式會同步 CABLE Input 的 Windows 音量與靜音。VB-CABLE 控制面板中的 Windows Volume Control 請保持預設關閉，避免同一份音量補償被重複處理。
- 前後時間差與影片嘴形同步是兩件需要分別檢查的事。藍牙仍有整體延遲，影片可在播放器調整聲畫同步；即時遊戲的操作延遲仍會存在。

四個位置使用共用數位時間軸與獨立補償。不同藍牙／USB 裝置的硬體時鐘仍可能隨時間漂移；本版尚未承諾長時間無漂移。聽到不同步或藍牙重連後，可重新驗證並量測。

## 設定與還原

四位置裝置組合、各位置延遲、播放模式及後方音量存於 `%LOCALAPPDATA%\DoubleSoundSurround\settings.json`。`status.json` 是最新程式狀態，包含時間、程序 PID 與路由狀態，不包含錄音。診斷時請同時確認 PID 存活及狀態時間是否新鮮。

取消「登入 Windows 時啟動」即可移除本程式的登入啟動項目。若搬動可攜資料夾，請在新位置重新勾選一次，讓啟動路徑更新。

虛擬端點原始格式備份於同目錄的 `endpoint-backups`。解除安裝 VB-CABLE 可執行官方安裝器並選 Remove Driver，完成後依官方指示重新啟動。它和All Around You Preview的程式資料夾是獨立安裝項目。
