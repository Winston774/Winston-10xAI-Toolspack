# W46 講義｜從四位置映射到可還原的音訊設定

## 1. 檢查與備份（20 分鐘）

從 W46 Release 下載完整程式 ZIP 與 SHA-256，驗證雜湊及完整解壓。了解程式未簽章、驅動可能需要 UAC／重啟。備份自己的舊設定與端點狀態，不使用其他人的設定。

## 2. 確認實體位置（20 分鐘）

列出本機裝置後，讓學員親自確認 FL 左前、FR 右前、RL 左後、RR 右後。名稱相同或共享立體聲端點時也要明確對應；同一來源不可再作輸出，以免回授。使用來源手冊規定的完整 ID。

## 3. 路由與實聽（30 分鐘）

有標準 VB-CABLE 就先檢查端點，缺少時才依原始手冊安裝。啟動前先通知測試音、調低音量；由學員確認四位置。全喇叭立體聲、模擬環繞及原音分流的後方行為不同，不把立體聲片源沒有後方聲道當作硬體故障。

## 4. 延遲校正（30 分鐘）

有麥克風時依手冊量測，全部位置有效再套用，並重新驗證；無麥克風則記為手動調整、未完成自動聲學驗收。重新連線、睡眠喚醒或移動座位後可能要再驗證。一次量測不代表永久同步。

## 5. 停止與還原（20 分鐘）

練習先還原 Windows 輸出，再退出常駐。視窗 X 會留在通知區，不能當作程式已停止。確認快照可用並保留備份。交付時分別記錄：命令成功、fresh status、使用者實聽、未測與阻擋；報告中的私人裝置資訊不公開。
