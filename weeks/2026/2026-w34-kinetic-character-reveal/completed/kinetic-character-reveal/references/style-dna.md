# Style DNA

## 核心定位

**Premium kinetic title sequence × streetwear campaign × anime character reveal**

它不是：
- 傳統動畫預告
- 純角色動作 montage
- 靜態海報輪播
- 一般科技 UI 宣傳片

它是：
- 以角色為身份錨點
- 以動態字體與平面設計為主體
- 以節拍與硬切為時間骨架
- 以圖形和角色的碰撞為視覺事件

## 視覺 DNA

### 構圖
- 極大字體與小型 UI 細節形成尺度反差
- 滿版色場與黑白高對比
- 圓、斜線、條帶、框線、切片、分割畫面
- 頻繁使用遮罩、窗口、前景 wipe 與海報式定格

### 色彩
採用五個角色色：
1. Base field
2. Dominant accent
3. Secondary accent
4. Neutral metal/grey
5. Contrast ink/black

色彩必須在角色服裝、場景色場、字體與粒子之間共享，避免角色與 motion graphics 像兩套不同作品。

### 字體
- 巨型、粗重、幾何、全大寫
- 短詞、品牌字母、編號與條碼
- 字體本身參與運動與碰撞
- 小型文字只作為 UI 密度，不承擔主要訊息

### 紋理
- Flat color
- Halftone
- Barcode
- UI ticks
- Wireframe grid
- Frost/speed particles
- Shutter flash

紋理只能增加速度與品牌感，不能讓畫面變髒或變成 grunge 拼貼。

## 動態 DNA

### 基本節奏
- 每一拍有清楚事件
- 主要元素快速進場、短暫停住、再硬退出
- 使用 impact shake、snap、slam、punch、stamp
- 避免漂浮、慢速柔順 easing 與長 dissolve

### 轉場家族
- Shape morph
- Graphic wipe
- Whip-pan
- Shatter handoff
- Foreground object wipe
- Flash / overexpose
- Freeze / release
- Split-screen collapse

### 物理互動
角色必須至少在 4 個 cuts 中直接改變圖形：
- 壓縮字體
- 踢碎字母
- 穿越字環
- 踏上網格
- 撞碎色片
- 被圖形框選或鎖定

## 攝影 DNA

使用高反差的鏡頭尺度序列：
- Extreme close-up identity clue
- Full-body lateral motion
- Split-screen analytical view
- Mid-air slow motion hero view
- Snap zoom portrait
- Dynamic perspective run-up
- Dive toward camera
- Clean centered end-card pose

鏡頭不是寫實攝影的主角；它服務圖形構圖與節拍。

## 敘事 DNA

沒有傳統故事情節，而是身份與能力的逐層揭露：

**符號 → 眼神 → 速度 → 技巧 → 個性 → 控場 → 英雄姿態 → 品牌識別**

## 同系列變體應保留的最低辨識度

至少保留：
- 動態設計主導
- 角色一致性
- 短而重的字體
- 角色與圖形物理互動
- 逐拍硬動作
- 功能不同的 cut 序列
- recurring motif progression
- hero climax + identity card
