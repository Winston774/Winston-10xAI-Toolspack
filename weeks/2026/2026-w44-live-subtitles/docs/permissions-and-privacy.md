# 權限、隱私與費用

## 擴充功能權限

| 權限 | 用途 |
|---|---|
| activeTab、scripting | 使用者啟動後，在目前分頁注入字幕介面與樣式 |
| tabCapture、offscreen | 在背景文件擷取所選分頁音訊並處理串流 |
| storage | 保存 API key、字幕設定及工作階段狀態 |
| YouTube 與 Google Generative Language 主機權限 | 對應播放器與 Gemini 連線；其他網站的存取依 Chrome 授權與頁面限制 |

## 資料流

使用者啟動後，所選分頁音訊經瀏覽器處理為 PCM，直接送至 Google Gemini；回傳的原文及翻譯用於顯示字幕與工作階段紀錄。分頁同時播放的其他聲音也可能被擷取。請勿使用未經同意的私人會議、個資或機密音訊。

API key 存在 `chrome.storage.local`，設定存取限制為擴充功能可信情境；這不是加密保險庫。連線時 key 會作為 Gemini WebSocket URL 的查詢參數，因此完整連線 URL、瀏覽器網路紀錄或診斷截圖可能包含金鑰，不應公開。使用專用、可撤銷的金鑰，必要時在 Google 端管理或撤銷。清除設定中的 key 可移除本機保存值。

Gemini 服務可能依帳戶用量計費，包括工具沒有播放的模型輸出。請先查看自己的配額與計費設定；本週沒有使用真實帳戶驗證費用或服務可用性。

## 分享前檢查

公開包不含使用者金鑰、`.env.local`、本機 token、私人逐字稿或測試媒體。學員應保護截圖、字幕紀錄和瀏覽器 profile；分享或匯出任何內容前自行檢查。
