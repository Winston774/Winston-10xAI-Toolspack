# 疑難排解

| 現象 | 處理方式 |
|---|---|
| 無法載入擴充功能 | 選 `completed/extension` 資料夾，確認有 manifest.json；使用 Chrome 116 以上 |
| 顯示尚未設定金鑰 | 到設定頁自行輸入並儲存，勿貼到聊天或教材 |
| Gemini 連線失敗 | 確認網路、key、帳戶對模型的存取、配額與計費狀態；不要分享含 key 的完整網路紀錄 |
| 開始後沒有字幕 | 確認目前選中的是發出聲音的一般網站分頁，音訊正在播放；停止後重整頁面重試 |
| 聽不到分頁聲音 | 停止擷取，確認分頁、系統與播放器音量，重新整理後再試 |
| 只有部分內容／錯誤 | 降低背景聲、使用清楚語音，對照原音；即時辨識與翻譯可能延遲或出錯 |
| 網頁無法注入 | 瀏覽器內部頁、限制注入的頁面或特殊播放器可能不可用；改用一般測試影片頁 |
| 切換目標語言無效 | 先停止字幕，選新語言後重新開始 |

回報問題時提供 Chrome 版本、頁面類型、可公開的重現步驟與錯誤文字；排除金鑰、連線 URL、私人音訊及字幕。
