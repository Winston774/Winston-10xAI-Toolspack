# W44｜Winston 雙語字幕

使用 Chrome 擴充功能，擷取目前分頁播放的聲音，透過 Gemini 即時辨識與翻譯，顯示原文和選定語言的字幕。支援調整字幕大小、位置、外觀及查看字幕紀錄。本週為 `0.3.0 Preview`。

預估 60 分鐘。你會安裝擴充功能、用自己的 Gemini API key 測試一段有權使用的影片，並記錄字幕品質與限制。

## 開始之前

- Chrome 116 以上、網路連線，以及可使用程式所指定 Gemini Live Translate 模型的 Google 帳戶與 API key。模型存取、配額與費用依帳戶當時的設定為準。
- 使用你有權處理的音訊；會議內容請先取得參與者必要同意。只擷取所選分頁播放的聲音，整個分頁的其他音源也可能被送出。
- API key 請自行在 Google AI Studio 取得，僅輸入自己的瀏覽器設定頁；不要貼在聊天、提交至 GitHub 或分享截圖。建議使用可撤銷的專用金鑰。

## 安裝與操作

1. 下載本週內容或 ZIP，解壓並保留完整資料夾。
2. 在 Chrome 開啟 `chrome://extensions`，啟用「開發人員模式」，按「載入未封裝項目」，選擇 [completed/extension](completed/extension/README.md) 資料夾。
3. 點開擴充功能，進入「設定」，貼上自己的 Gemini API key 並儲存。可按「測試 Gemini 連線」；這項測試會連線，但不傳送音訊。
4. 開啟有聲音的影片或網頁會議分頁。點擴充功能圖示，選目標語言後按「開始雙語字幕」。
5. 觀察原文與翻譯，使用畫面上的「字幕紀錄」回看；換目標語言前先停止。完成後按「停止」。

此版擴充功能直接連接 Gemini，不需要啟動本機 gateway 或 Node.js。操作前請閱讀[權限與隱私](docs/permissions-and-privacy.md)。

## 成果證據與通過標準

- 在取得同意的測試音訊上，觀察原文與目標語言字幕是否出現、是否跟隨播放。
- 對照至少三句原聲，記下辨識錯字、翻譯誤差與延遲；字幕內容應自行查核。
- 驗證暫停／繼續、停止，以及字幕位置或大小變更；截圖前遮住金鑰與私人內容。
- 若連線失敗，先停止字幕，確認網路、金鑰及帳戶對模型的存取權，再依[疑難排解](docs/troubleshooting.md)重試。

## 重要限制

API key 以 `chrome.storage.local` 存放，並非加密保險庫；分頁音訊會傳送至 Google Gemini，可能產生費用。WebSocket 連線會使用包含 API key 的查詢參數，請勿分享完整連線 URL 或瀏覽器網路紀錄。字幕可能有錯誤、延遲或缺句；瀏覽器內部頁、桌面程式及使用者自己的麥克風不在此擷取範圍。網站、播放器、版權保護及 Chrome 更新都可能影響功能。

未使用真實金鑰或播放私人媒體進行端到端驗收；首次安裝、現場影片／直播／網頁會議與實際帳戶費用均需學員自行確認。詳見[驗證紀錄](docs/verification.md)及[課堂講義](lesson.md)。
