# 課堂講義｜用雙語字幕理解外語內容

## 1. 設定邊界（10 分鐘）

選一段公開且允許使用的短影片；若使用會議錄音或現場會議，先取得必要同意。確認 API 帳戶可用模型、費用與使用限制。先安裝擴充功能並在設定頁自行填入金鑰。

## 2. 執行一次字幕（15 分鐘）

打開影片分頁並播放，選擇目標語言、開始字幕。聆聽原音，同時觀察原文與翻譯的變化。調整字幕大小與位置，練習暫停、繼續、停止及查看字幕紀錄。

## 3. 做品質檢查（20 分鐘）

選三句含專有名詞、數字或轉折的內容，記錄原聲、字幕與你修正後的理解。注意原文辨識錯誤會影響翻譯；把無法確認的內容標成待查，避免把即時字幕直接當成逐字稿。

## 4. 整理交付（15 分鐘）

交出一張遮除私人資訊的操作截圖，以及三句對照表、發現的限制和一項改善建議。不分享 API key、完整 WebSocket URL、私人會議內容或其他人的個資。

如有無字幕、無聲音或連線失敗，先按停止，再參照[疑難排解](docs/troubleshooting.md)。本週工具屬 Preview，實際模型可用性與費用依帳戶而異。
