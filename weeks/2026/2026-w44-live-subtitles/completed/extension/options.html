雙語字幕設定

填入自己的 Gemini API key 後，在發出聲音的分頁按「開始雙語字幕」。分頁音訊會直接傳送至 Google Gemini 辨識與翻譯。

Gemini API

載入中

到 Google AI Studio 取得 API key ↗。字幕執行中無法更換金鑰，請先停止字幕。

使用說明

  1. 貼上 Gemini API key 後儲存；「測試 Gemini 連線」會檢查目前的目標語言，不傳送音訊。
  2. 開啟要翻譯的影片、直播或 Meet／Zoom 網頁版分頁。
  3. 點擴充功能圖示，或按 Alt + Shift + U 開啟控制面板，選擇目標語言後按「開始雙語字幕」。
  4. 先前的字幕可從畫面右上角的「字幕紀錄」回看。換目標語言前請先停止字幕。

資料與費用

API key 儲存在這台瀏覽器的 chrome.storage.local，只限擴充功能頁面存取，不會透過 Chrome 同步。此空間並非加密保險庫，請使用可撤銷的專用金鑰。

開始字幕後，所選分頁播放的聲音會直接傳送至 Google Gemini，使用量依你的 API 帳戶計費。只擷取該分頁，不含其他分頁、桌面軟體或自己的麥克風。
