# 疑難排解

| 症狀 | 重試方式 |
|---|---|
| Chrome 找不到 manifest | 選 `completed/video-bridge/extension`，不要選整個週次或未解壓 ZIP |
| 更新後無回應 | 在擴充功能頁重新載入，再重新整理 X／Threads／Facebook 分頁 |
| X 仍顯示自己的右鍵選單 | 直接在影片畫面按右鍵，確認沒有按 Shift，並重新整理來源頁 |
| 找不到來源／右鍵上下文過期 | 先播放影片，開啟原始貼文，重新右鍵後立即選操作 |
| 多支影片、封面不符、缺少 MP4 | 回原始貼文播放目標影片；仍無法唯一匹配時保留錯誤，改用來源提供的下載方式 |
| HTTP 錯誤、網址失效、逾時 | 重新整理原始貼文再取得新網址；確認網路與站點存取，稍後重試 |
| 檔案過大 | 選小於 150 MiB 的片段；本版不切片或合併串流 |
| 已交給 Chrome 下載但找不到檔案 | 查看 Chrome 下載項目、預設下載位置及另存提示；面板可重新另存 |
| 下載取消／中斷 | 快取仍可使用，從面板另存；Chrome 完成狀態須另確認 |
| 貼出 video-bridge 識別文字 | 確認接收頁已載入外掛，使用新貼文視窗；可點浮動插入按鈕或用 MP4 手動選檔 |
| 剪貼簿標記過期 | 面板「準備再次貼上」取得目前影片標記，或用插入按鈕使用目前快取 |
| 找不到影片附件欄位 | 先點 Threads「附加影音內容」／Facebook「相片／影片」，再重試插入 |
| 多個視窗／輸入區／附件欄位 | 只保留一個一般新貼文視窗；關閉後重開，避免回覆或多段串文 |
| 已插入、移除後不能再插入 | 關閉並重開發文視窗，重新確認附件 |
| 提示已交給平台但無預覽 | 檢查平台相容性、格式和處理狀態；改用已下載 MP4 手動選檔並記錄差異 |
| 想清理資料 | 面板清除快取；另複製文字移除舊標記；下載檔及平台附件自行移除 |

回報時提供 Chrome／外掛版本、來源平台、操作入口、錯誤原文與是否出現附件預覽。遮蔽私人貼文、帳號、媒體簽名 query 與瀏覽器內部資訊。請勿提供 Cookie 或登入 Token。
