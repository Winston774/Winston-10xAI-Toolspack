# Chrome 載入入口

在 Chrome 120+ 開啟 `chrome://extensions`，啟用開發人員模式，點「載入未封裝項目」並選擇本資料夾。確認「影片接力 Video Bridge」v0.3.0，再重新整理 X、Threads 與 Facebook 分頁。

在 X／Threads 影片畫面上按右鍵，選「下載並複製影片・影片接力」，確認下載完成後，到 Threads 新串文或 Facebook 一般發文框按 Ctrl＋V／插入按鈕。

插入附件可能立即上傳，發布由你操作。剪貼簿標記需同一外掛接收，快取單支上限 150 MiB。本版 Preview，實際附件預覽與平台處理狀態須自行確認。

操作、開發測試及限制見 [成品說明](../README.md) 與 [本週教材](../../../README.md)。
