# 已知限制｜v0.1.1 Preview

- 兩支 Python 程式負責證據準備與索引驗證。視覺理解、聆聽、OCR、ASR 由 Agent 可用能力提供，未綁定特定模型。
- helper 只接受本機檔案；沒有網址下載、影片生成、剪輯或渲染。
- 概覽抽樣會漏掉瞬時事件；需針對問題補看密幀或播放。
- 圖片自動轉正、正規化像素比例，寬度上限 1280 px。小字判讀需回原片或另取原尺寸。
- 自動音訊輸出僅第一條音軌、16 kHz mono PCM16；混音、空間與完整頻寬判斷需回原片。
- 局部抽樣仍先掃完整片的時間戳。工具以短片為主要用途，沒有內建子行程 timeout 或全面資源配額。
- 某些片尾長度由影格間距估計；依 manifest 的 duration_basis 判讀精度。
- 檢查器不解碼證據檔，也無法核實宣告的媒體類型、實際觀看或分析正確性。
- 本次驗證為 Windows、Python 3.11、FFmpeg 8.0.1 的合成測試。macOS／Linux、真實影片全流程與人工視聽品質未在本次驗收。
