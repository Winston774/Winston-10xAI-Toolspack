# 保存聲音、來源色系與視覺設定

設定保存的是選擇和可追溯證據；不能把一次喜歡的聲音、某支影片的色系或技術試跑當成往後所有影片的核准。

## 聲音選單與換聲

以 [voice-selection.json](../templates/voice-selection.json) 保存配音服務、成本狀態、聲線 ID／情緒、參考授權及試聽。聲線名稱是顯示值，穩定 ID 才用來生成和追蹤。可提供少量候選短試聽，讓使用者選腔調與自然度；沒有必要預設固定性別或特定聲線。

先檢查既有偏好和授權。已確認的服務／成本／聲線不重問；服務、使用方式或成本改變，才補缺少的必要決策。沒有可用服務也可接受使用者的 WAV。不自動呼叫付費 API、下載模型、複製真人聲音或把原片送往新的服務。

將參考音或音库留在合法可讀的來源位置，設定只保存 locator／授權／hash。模型、私有参考音與金鑰不打包進共享 Skill。若依賴其他專案的模型／runtime／聲包，明示必須保留該依賴；不能宣稱單一資料夾可攜。

每次生成保存實際輸入稿、原始 WAV、服務／聲線設定及 SHA。偏好的核准 scope 例如「此短試聽的腔調與自然度」，不代表新稿中的英文姓名已讀對。核聽專名後綁定當前 WAV 與範圍；換聲、改稿或 WAV bytes 改變，需要重生聲音、實測長度並重新對齊字幕和卡片，不能沿用舊配音的秒數。

響度／速度處理各有明確負責階段。保存原始與已處理輸出之間的 hash 關係，後續渲染直接使用已處理音檔，不再正規化或加 limiter。沒有處理證據時寫 `unknown`；不能只改欄位成 `normalized_once`。峰值要量測原生立體聲；單聲道診斷下混可能放大峰值，不能因此替成片任意降低音量。

## 同品牌，不同內容色系

將設定分成兩層：

| 共用品牌骨架 | 按來源保存的主題 |
|---|---|
| 字型、標題／字幕層級、品牌鎖定、字幕區、人物照片方式、動畫語彙 | 底色、墨色、輔色、強調色、標記樣式、概念插畫內容 |

同一來源拆成多支精華時，共用來源主題，不讓各集各自改色。`watch`、`youtu.be`、`shorts`、`embed`、`live` 都可能指同一 YouTube ID；先正規化來源識別，其他來源用明確的同源 ID。新的來源可以換色，但共用排版和動畫語彙讓出版風格一致。

主題 registry 範例見 [source-themes.json](../templates/source-themes.json)。編輯式 adapter 必須讀 registry 的 key；使用 snapshot 時同時比對 registry SHA/key/palette，避免複製舊快照後形成同來源不同色。修改 registry 後新 render 才套用，旧片保留；保存 resolved palette、字型及設定 SHA。

不要只提供任意 JSON 欄位而假裝 renderer 都會採用。特定 renderer 固定 1080p30 或只支援特定卡片樣式時，拒絕未支援設定。正文、次要文字、強調標記與字幕都檢查對比；深色強調色通常可搭白字，淡色標記需搭深字，按實際色值量測。

## 字幕不是兩份文字硬疊

英文原訪談可採繁中在上、英文在下；短中文導讀只放繁中是另一個獨立選項。字幕語言與大小依使用者、畫幅及讀者決定。編輯式 1080p preset 用繁中 56px／英文 34px、各最多兩行、固定下方閱讀區。字級改變須重新量測最長 cue 和安全區，不能以語言切換遮住人物嘴部。

保留 `en_raw`、來源索引、修正原因與候選時碼。ASR 重複、跨 cue 字詞及假起句可有依據地整理顯示文，但不把流暢的改寫當成逐字核對。字幕按真實語句分段；Latin 人名整詞換行，不拆成上下兩個殘詞。字型先確認繁中字形與靜態字重可用，再產生本片本機 WOFF2；避免未經驗證的變動字型在 libass 顯示方框。
