# 可重用的視覺系統

附帶的編輯式紙張模板以紙白、墨黑與黃色重點組成，適合繁中導讀和來源影片。它是可選的起點；使用者有品牌或其他風格時，先建立相應版型與檢查規則，再驗證成片。通用的原則是資訊層級、來源忠實、可讀性與動態節奏。

## 先定閱讀層級

畫面一次突出一個主要問題或答案。主題句、人物名、職務、來源歸屬和字幕使用固定的字級關係；同類元件共用字體與間距，不逐場臨時另做一套。

- 大標題只承載當前問題或最必要的概念。
- 中文字幕為主要閱讀層級，英文來源字幕較小；不以小字塞滿逐字稿。
- 來源署名、品牌與進度使用次要層級，不能搶走人物和答案。
- 片尾把原片來源與觀眾下一步分清楚，不堆重複資訊。

選擇涵蓋實際中文字形的合法字體；姓名與術語混排時檢查字重、基線與標點。字體實際出現在畫面上才能算檢查完成，僅填 font-family 不能保證正確載入。

## 內建字幕撕紙底圖

內建模板所有旁白及來源場景共用不規則 SVG 撕紙邊。黑底承托字幕，紙邊提供輕微變化；它的功能是穩定文字對比與維持紙張視覺。

`build_film.py` 透過 `visual_contract.py` 注入共用字幕元件。若採此模板，保留共用元件，不在個別場景改回平直黑矩形。`check_style.py` 可檢查結構及影格邊緣，但仍須人眼確認沒有被裁掉或遮住。

最長的中英字幕各抽一格，檢查左右留白、行高、兩語間距與人物嘴部安全區。英文原句未取得時不要編造，中文來源可將 `en` 留空。

## 來源影片縮入、逐點整理、還原

每個 source item 先判斷是否需要動畫整理，將結果寫進 `markers.json.review`。條件、流程、對比或容易混淆的規則通常值得標示；原畫面已清楚表達時，可保留原畫面並記錄理由。

題數、marker 數、卡片數與每卡重點數都沒有固定配額。只在來源確實說到時逐點顯示；卡片不能提前替講者補結論，也不能把條件或例外刪掉。

內建 marker 的動作為：全幅來源 → 0.7 秒縮入 → 依原片時間逐點揭示 → marker 結束 → 0.7 秒還原。穩定態來源位置為 `x=625, y=64, scale=0.66`；原音保持 1x。

卡片與縮入畫面有約 49 px 的刻意重疊，形成清楚的前後層級。檢查每個鏡位，避免遮住眼睛、嘴部、重要手勢、圖表和原片字幕。重要資訊無法避開時，調整布局或重設該段，而非只縮小字體。

`markers.start/end/steps.at` 全部是原片秒數。結尾保留還原時間，下一段不應打斷影片恢復動作。長重點以 `display_lines` 明確斷行，斷行後仍須保留原文字義。

## 黃色標記、人物卡與進度

黃色適合標示問題中的關鍵短語、重要對比或段落轉折。內建橋段可用黃色背景凸顯末行；這不代表每一段都必須亮黃，也不自動等於手繪線條動畫。需要畫線效果時，以實際完成的動畫與影格檢查為準。

人物卡交代姓名、與本題相關的職務和一項背景。照片使用真實來源或有權使用的肖像。採膠帶語彙時，讓膠帶跨過照片框與背景，位置和尺度在所有人物卡一致；箭頭若存在，端點要清楚指向目標。

右上角品牌和進度以同一視覺中心對齊；圖示內留白避免問號等字形頂到邊緣。進度分母從實際題目數產生，不能寫死為五。

先檢視原片的台標、來源浮水印、投影片標題與人名條，再放品牌／進度。若互相重疊，調整自己的覆蓋物；來源歸屬仍須可見。內建模板不能自行理解每個鏡位的安全區。

## 縮圖另做資訊設計

預設 `photographic-closeup-white-yellow-v1` 使用真實人物近景、自然景深、文字側適度壓暗、上下兩層大標題。它的用途是讓觀眾迅速理解人物與核心問題；片內紙卡不必原封不動拿來當縮圖。

`thumbnail-brief.json` 使用 `headline_context` 與 `headline_question` 表達兩層內容。預設可分別用白、黃；自訂風格時保持語意欄位，不把顏色當內容。

學員提供並實際看過參考圖後，填 `reference`、`reference_viewed`；沒有參考圖時，填完整 `art_direction` 並完成 `art_direction_reviewed`。不得虛構已看過的參考，或沿用別人的人物與文案。

`style` 必須與 `profile.thumbnail_style` 一致，可選預設或 `custom`。自訂風格需清楚寫下構圖、文字層級、背景和品牌方式，再建立對應成品。

縮圖 output 必須指向實際檔案。實看後才勾選手機可讀性、肖像忠實、承諾與首答一致、風格與方向一致、已檢視縮圖等 review 欄位，並記錄判斷證據。

Image Gen 可用來探索原創背景、概念草圖或圖像；人物身分、字幕文字與可核實職務不能交由圖像猜測。若使用生成素材，保存提示、輸入來源與可用授權資訊。

## 片尾與動態節奏

片尾的來源側顯示原頻道、原標題或吸引觀眾看完整版的主題，以及實測片長一次。行動側用本頻道名稱與簡短訂閱邀請；不加入解釋製作流程的口號。

文字進場先建立閱讀順序，再把焦點交給來源。旁白結束後留必要呼吸，讓問題被理解後再切場；停留時間由句子難度與實際聲音決定。內建預設是起點，不能取代試看。

## 範圍與驗收

附帶 renderer 固定 1920×1080、30 fps。直式或其他尺寸需改構圖、字幕、安全區、HUD、marker 與驗證規則；不能只改 canvas 便聲稱完成。

附帶 builder 只接受 `paper-tear-and-semantic-reframe-v1` 的影片契約；將 `thumbnail_style` 改成 `custom` 只會改變縮圖方向的驗收，不會替影片自動產生新風格。更換整體影片模板時，須調整 renderer 與檢查規則。實際驗收流程見 [品質與交付](quality-and-delivery.md)。
