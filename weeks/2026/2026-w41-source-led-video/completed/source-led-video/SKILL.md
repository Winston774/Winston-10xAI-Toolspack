# 原音精華影片製作

讓原片中的講者回答觀眾真正關心的問題。新旁白只做必要背景、問題引導與收尾，保留原說法的條件、例子與上下文。影片長度、頻道品牌、聲音來源與視覺方向依本次需求設定。

## 選擇工作方式

- **只要分析或企劃**：取得可用逐字稿／原片，完成來源整理、候選評分、問題順序、標題與縮圖 brief、旁白及 rundown。只用 Python 標準函式庫即可操作資料工具；不要求先裝渲染器或取得聲音模型。
- **要完成影片**：沿用上述企劃，再準備原片、每段旁白 WAV、字幕與視覺資產，依[快速上手](references/quickstart.md)建置並驗證本機工程。希望使用編輯式雙語與短句逐點淡入時，改讀[editorial motion](references/editorial-motion.md)。
- **修改既有影片**：先讀當集 brief、核准項目與 QA。只修改本次指定範圍；改稿、改音或改字幕後重新解析時間軸。短樣片與完整片分開標示，核准樣片不等於完整版已重渲染。

來源尚無法取得時，記下缺口與可行替代；不以標題、縮圖或來源摘要冒充全片理解。下載失敗只代表取得途徑受限。影片公開上傳依當次使用者指示處理。

## 製作順序

| 階段 | 必須形成的內容 | 檢查重點 |
|---|---|---|
| 收件 | 來源、觀眾、觀看承諾、片長需求、頻道與輸出方式 | 缺少品牌不妨礙企劃；輸出前填好品牌。沒有指定最低片長時不湊時長 |
| 全片理解 | 時碼逐字稿、主題覆蓋、事實與預測的區分 | 全片讀過／能聽看的範圍與尚待核對項分開記錄 |
| 選段 | 候選切點、三項語意門檻、八維評分與證據 | 斷章取義或意思不完整的候選不能靠高分通過 |
| 編排 | 觀眾問題、首題比較、hook、標題／封面承諾、rundown | 第一個實質原音答案兌現標題與封面提出的問題 |
| 導讀 | 主持／節目定位、來賓背景、why-now、原語術語表 | 背景要真的講出來；單人來源介紹講者，不捏造對談 |
| 聲音與字幕 | 實際 TTS 輸入或錄音稿、WAV、逐句字幕、核聽紀錄 | 原音不變速；旁白依實際音檔定時，姓名按原語言核聽 |
| 畫面 | 主題卡、人物卡、來源逐點重點、進度、CTA、縮圖 | 同類元件一致，字幕清楚，重點卡保護人物與原片圖表 |
| 驗證交付 | 影片、縮圖、標題、來源說明、章節、字幕、工程及 QA | 實測長度、完整解碼、抽格及視聽狀態都有明確證據 |

## 重要製作規則

1. **內容決定題數。** 不預填五題，也不限制每題重點數。合併重複問題；重要的來源內容保留足夠時間。
2. **標題承諾先回答。** 比較全片候選後決定首題，可以重排原片順序。hook 與人物介紹保持精簡，第一段原問答直接處理觀眾點進來想了解的事。
3. **原音承擔主要答案。** 保留必要提問和回答；旁白不搶先講完答案，不添加與本題無關的個人經驗。語句俐落，但問句與換場需留理解時間。
4. **短背景也要完整。** 以少量句子說清楚誰訪問誰、節目定位、一項可查的代表背景、來賓相關角色及此刻值得談的原因。人物卡不能代替口播；日期、職位與數字需要來源。
5. **保留原語專名。** 人名、品牌及特定術語保留原文，需要時加中文解釋。實際送進 TTS 的文字必須與正式稿一致；中文字音譯不可代替英文原名。生成後核聽，不由拼字或 ASR 推定發音正確。
6. **量測實際聲音。** 旁白可以自錄或使用已配置的 TTS；聲音工具由使用者環境決定。先試短段再批次製作，速度只處理一次，依 WAV 時長安排字卡、字幕與停頓。
7. **重點動畫服務理解。** 審閱每段來源，選擇逐點註記或保持原片，留下理由。內建紙張模板提供撕紙字幕帶、原片縮入、逐點揭露及還原；黃色用來強調少數關鍵語句。
8. **縮圖與片內畫面分工。** 縮圖要在小尺寸呈現清楚承諾與主角；可選照片近景、深色文字區及對比標題，也可使用當集選定風格。來源人物不用模型想像，文字由可編輯圖層排版。
9. **片尾有明確行動。** 交代原來源頻道、主題與完整版連結，時長不重複；依頻道需求邀請訂閱或採取下一步。
10. **驗證狀態如實記錄。** 未確認分數留 `null`；未聽看就保留待核。欄位、雜湊、解碼及抽格通過不代表完整影音已驗收。

## 執行範圍

`scripts/interview.py` 提供初始化、評分、剪輯、時間軸解析與檢查；`scripts/build_film.py` 建立可編輯的 HyperFrames 工程。原 paper 模板與新增 editorial-motion adapter 都支援 1920×1080、30 fps。後者以已準備的媒體及明確字幕/卡片計畫建置完整或短片，提供繁中／英文雙語與逐點縮入還原；更換畫幅、字體或布局後須另行驗證。

工具不會自動取得來源影片、呼叫 TTS、下載模型或安裝其他技能。學員可先完成企劃，再依環境接上剪輯與渲染能力。若使用其他剪輯器，保留同一份 rundown、字幕、來源時碼與驗收方法；不可把工程檔宣稱成已輸出的影片。
