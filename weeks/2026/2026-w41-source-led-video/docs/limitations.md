# 已知限制與使用邊界

- 未知分數為 `null`；工具不會自動閱讀或理解網址、語音、全片語義，也不替你完成來源事實核對。
- `complete_thought`、`context_preserved`、`faithful_claims` 須明確成立；自填布林值仍需要真實證據。數值評分無法越過門檻。
- `doctor` 主要檢查路徑及 Python import，`execution_verified` 為 false；可找到執行檔不等於能成功完成渲染。
- 專名核聽檢查驗證目前 WAV、範圍與審閱欄位，沒有自動辨音或實際聆聽；來源整片審閱旗標也屬審閱者聲明。
- 內建版型僅 1920×1080、30 fps。直式或新視覺風格需額外版型開發及驗收；修改縮圖 brief 不會重做影片版型。
- `build_film.py` 產出 HTML 工程，沒有直接輸出 MP4。外部 HyperFrames、瀏覽器與 FFmpeg 必須另備；原始操作基準固定為 HyperFrames 0.8.119，換版本需重新核對參數與測試。
- `cut` 要求來源同時有影像及音軌；純音訊或無音軌影片須先另行準備合適輸入。旁白處理以 PCM16 WAV 為基準。
- 初始品牌空白，建片前需填寫自己的名稱。題數、片長、聲音工具與素材由每案決定；不預設個人頻道、聲音或八分鐘長度。
- 部分 QA 與生成工程可覆寫舊的計算輸出；`init`、`cut` 等雖有拒絕覆蓋檢查，仍應備份已核准版本並以新目錄做實驗。
- 紙感字幕帶、縮放和重點卡需要實際影格與動態檢查；程式結構通過無法保證人臉、字幕、節奏或資訊密度都恰當。
- v1.0封裝時未重新完成瀏覽器畫面檢查、最終 MP4 渲染、真實旁白核聽與完整人工音畫驗收，因此維持 Preview。

## v1.1 新adapter範圍

- 只建置已準備好的16:9/30fps MP4原音clip、WAV、authored字幕/卡片；不是自動取源、翻譯或配音產品。
- 固定1080p30、56/34字幕及2–3點圖解；任意來源／人物／聲線／段數，但需要自己提供媒體与有根據的字詞/時碼。
- WAV和clip不再次loudnorm；unknown處理狀態不升格。需要新配音時先確認服務/成本/試聽並重新對齊。
- 新版為Preview；合成adapter測試、兩個實際完整剪輯的技術證據及人工核聽狀態分開；跨平台與語意/聽感不由合成測試保證。
- render wrapper需要自己安裝的HyperFrames、GSAP、Chrome及FFmpeg/FFprobe；不包runtime/模型/字型或自動npx下載。
