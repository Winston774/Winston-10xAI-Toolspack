# 隱私、聲音權利與安全

## 資料流

| 資料 | 預設位置 | 是否進入 Git |
|---|---|---|
| 聲紋／情緒上傳暫存 | `outputs/htmlui/uploads/` | 否；每次工作後刪除 |
| 生成 WAV | `outputs/htmlui/` | 否 |
| JSON 生成參數與原始文字 | `outputs/htmlui/` | 否 |
| 模型權重 | `checkpoints/` | 否 |
| 程式碼與教材 | Repository | 是 |

服務預設只監聽 `127.0.0.1`。首次安裝與模型缺檔時會連線下載 Python 套件、IndexTTS 2.5 權重及必要資源；語音推論本身在本機執行。本工具不要求 API Key。

## 聲音使用原則

- 只使用自己的聲音，或已取得明確授權且符合用途範圍的聲音。
- 不合成政治人物、公眾人物、未授權個人或未成年人的聲音。
- 不用於詐欺、冒用、誤導、騷擾、歧視、散播假訊息或規避身分驗證。
- 公開合成內容時，清楚揭露它是 AI 生成，並依所在地規則處理同意、標示與個資。
- 不把聲音或輸出用於醫療、信用、就業、軍事、關鍵基礎設施、大規模生物辨識等高風險決策。
