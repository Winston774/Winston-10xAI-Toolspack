# IndexTTS 2.5 能力實驗流程

這份流程用 Index Studio 驗證模型宣稱的能力。每組只改一個變因，固定聲紋音檔、Seed 與採樣參數，生成後保留 WAV 與同名 JSON。

## 固定基準

- 聲紋音檔：同一位說話者，乾淨、單人、5 到 15 秒。
- Seed：固定為 `42`。
- Temperature：`0.8`。
- Top P：`0.8`。
- Top K：`30`。
- Num Beams：`3`。
- 每個條件至少重複兩次，第二輪可更換 Seed 檢查穩定性。

## 實驗矩陣

| 編號 | 能力 | 固定條件 | 唯一變因 | 比較重點 |
| --- | --- | --- | --- | --- |
| E01 | 聲紋複製 | 中文短句、沿用聲音情緒 | 聲紋音檔 | 音色相似、清晰度、雜音 |
| E02 | 跨語言 | 同一聲紋、同一語意 | ZH、EN、JA、ES、AR | 音色保持、口音、可懂度 |
| E03 | 情緒與聲紋分離 | 同一聲紋、同一句話 | 沿用聲音、情緒參考音檔 | 音色是否穩定、情緒是否改變 |
| E04 | 八維情緒 | 同一聲紋、同一句話 | 單一向量 0.0、0.4、0.8 | 強度梯度、失真、情緒辨識 |
| E05 | 文字情緒 | 同一聲紋、同一句話 | 平靜、緊張、悲傷描述 | 描述跟隨、內容清晰度 |
| E06 | 語速控制 | 同一聲紋、同一句話 | 0.75、1.0、1.25 | 實際長度、自然度、咬字 |
| E07 | 發音控制 | 同一聲紋、同一句話 | 原文、`<字詞|發音>` 標註 | 多音字或音素是否正確 |

## 單次操作

1. 上傳固定聲紋音檔。
2. 套用「能力實驗」中的對應範本。
3. 檢查本輪唯一變因，其他設定維持基準。
4. 生成並播放 WAV。
5. 開啟 `outputs/htmlui/<task-id>.json` 確認參數。
6. 在下一輪只修改預定變因。

## 驗收邊界

- API 與靜態測試驗證檔案、參數與工作流程能正確串接。
- GPU 檢查驗證 PyTorch 能辨識硬體。
- 聲紋、情緒、語速與發音品質都需要實際下載 checkpoints 後聆聽評估。
- 若要做客觀評測，可在後續模組加入 ASR WER、說話者嵌入相似度與音訊品質檢測。這些指標目前尚未實作。
