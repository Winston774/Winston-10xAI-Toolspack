# Index Studio changelog

## 1.0.0 - 2026-08-13

- Added a dependency-free single-file HTML workbench.
- Added a loopback FastAPI bridge with isolated uploads and serialized GPU inference.
- Added Taiwan Traditional Chinese input preservation with internal `tw2s` conversion.
- Added five-language synthesis, four emotion modes, duration control, pronunciation annotations, sampling controls, WAV downloads, and JSON run metadata.
- Added Windows launchers, learner documentation, release validation, and CI.
- Applied the Noise Winston Calm / Signal visual system with light and dark themes.
