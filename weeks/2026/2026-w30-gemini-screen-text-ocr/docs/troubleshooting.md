# 疑難排解

## 快捷鍵完全沒有反應

依序確認：

1. 目前游標不在網址列、輸入框或可編輯區域。
2. 不是 `chrome://`、Chrome Web Store 或 Chrome 內建 PDF viewer。
3. 到設定頁確認對應快捷鍵已啟用，而且兩組組合不同。
4. 到 `chrome://extensions` 按「重新載入」，再重新整理測試網頁。
5. 若是 `file://`，在 Extension 詳細資料開啟「允許存取檔案網址」。

## 第一次只按快捷鍵時截圖失敗

確認 manifest 版本為 `0.6.2`，並且 `host_permissions` 包含精確的 `<all_urls>`。舊版只靠 `activeTab` 時，自訂頁面快捷鍵不會取得截圖權限。更新檔案後必須同時重新載入 Extension 與重新整理既有網頁，舊 content script 才會被替換。

## 框選完成後預覽失敗

- 框選範圍必須至少 16 × 16 CSS px。
- 開始拖曳後不要捲動、縮放、切換分頁或導航；這些動作會安全取消舊座標。
- 先用一般圖片頁測試；DRM 影片、Picture-in-Picture、真正全螢幕或企業 DLP 畫面可能是黑畫面。
- 快速重複操作時，等待最新一個工作出現；舊工作本來就會被淘汰。

## 完整可視區偶爾失敗

Extension 會把 screenshot 呼叫至少間隔 550 ms。若頁面正在導航、分頁已切換或 Chrome 暫時無法擷取，請停在目標分頁後重新按一次。不要在一秒內由其他截圖 Extension 同時連續觸發多次擷取。

## Gemini 測試失敗

| 畫面訊息類型 | 檢查方向 |
|---|---|
| API Key 無效／權限不足 | 建立新的 Gemini 專用 Key，確認限制與專案 |
| 模型不存在／不支援 | 改用 `gemini-3.1-flash-lite`，查看官方模型頁 |
| 地區不可用 | 查看 Available regions；免費層不支援時可能需 Billing |
| 配額已用完 | 到 AI Studio 查看 RPM、TPM、RPD 與方案 |
| 請求格式 | 確認已重新載入最新 Extension；再換預設模型測試 |
| 暫時性錯誤／timeout | 檢查網路與服務狀態，稍後再試 |

詳細設定請看 [Gemini API Key、模型與免費層](gemini-api-setup.md)。

## OCR 結果不準

- 暫停影片，避免框選期間換影格。
- 放大網頁，使文字清晰但仍完整落在可視區。
- 只框必要文字，避免背景圖案與不相關 UI。
- 優先使用高對比、水平、沒有遮擋的內容。
- Gemini 是生成式多模態模型；人名、數字、程式碼與法規內容必須人工核對。

## 設定頁說 Key 已設定，但仍不能使用

「API key 已設定」只代表瀏覽器 storage 裡有值，不代表 Google 已驗證。必須再按「測試 Gemini」。若舊 Key 的限制或專案狀態改變，建立新 Key 後貼上並儲存，舊值才會被覆寫。

## 回報問題時需要什麼

- Chrome 版本與作業系統。
- Extension 版本（應為 `0.6.2`）。
- 操作頁面類型，但不要貼私人 URL。
- 從重新載入 Extension 開始的最短重現步驟。
- 去除 API Key、個資與敏感內容後的錯誤畫面。
- 問題屬於框選、完整可視區、Gemini、翻譯或單字庫哪一段。
