框選區域
完整可視區

兩組快捷鍵不能相同。快捷鍵至少需要 Ctrl、Alt 或 Meta 其中一個修飾鍵；不會在輸入框、文字區域或可編輯內容中觸發。請避開 Chrome、作業系統或網站保留的組合鍵。Chrome 內建頁面與內建 PDF viewer 不支援擷取。

04

使用說明

  1. 到 Google AI Studio 建立 API key。
  2. 貼上 API key 後儲存。
  3. 在一般網頁或本機檔案反白文字，右下角出現小 icon 後，把滑鼠移到 icon 上。
  4. 要辨識圖片或影片文字，先暫停影片，再按 Alt + Shift + X 直接框選，或按 Alt + Shift + V 擷取完整可視區；兩組快捷鍵都能在上方調整。
  5. Side Panel 只會在你確認後把裁切區送給 Gemini；OCR 圖片與結果不會寫入歷史。
  6. 如果要支援 file:// 本機檔案，請到 chrome://extensions 的此插件詳細資料頁開啟「允許存取檔案網址」。
