# 隱私、資料流與分享

## 分發包內容

包含遊戲原始碼、合成測試、啟動工具與教材。沒有任何真實 API Key、Cookie、郵件資料、原始參考影片、分析畫格、使用者遊戲紀錄或個人部署設定。

## 你填入金鑰後會發生什麼？

1. 前端清空輸入欄位，把金鑰暫存在目前分頁的封閉 JavaScript 記憶體。
2. 單步即時執行把金鑰放在 Authorization header，經同源 /api/jev 轉送至 TypeSafe。
3. 同時傳送棋盤、方塊、候選結果與判斷問題。預設遊戲狀態不含郵件或人物資料。
4. Worker 不保存全域金鑰、不讀環境金鑰、不使用資料庫／快取／應用日誌保存請求。
5. 回應只保留允許的答案欄位與用量；原始上游錯誤、標頭與 debug 內容不回傳。
6. 匯出 JSON 不含金鑰；遊戲紀錄只保留在分頁，重新整理前請先匯出。

清除、離頁、重新整理會移除應用程式持有的金鑰，並嘗試取消請求。已送出的網路請求可能已被接收或計費；不宣稱即時抹除傳輸層記憶體或遠端紀錄。

應用程式沒有持久保存金鑰。瀏覽器擴充套件、密碼管理器、託管商和 API 供應商有各自政策，請自行確認；不要在不信任的共用電腦填入金鑰。

## 用量與發布

每個完整 live 回合為 3 批請求，失敗或停止也可能已送出部分請求。畫面顯示 API 次數與輸入 Tokens，匯出另含回傳的 input／output usage；這些值無法取代供應商帳單。範本沒有金額上限，先做單步測試。

本機服務只監聽 127.0.0.1。不要直接把它改成公開的任意 proxy；若自行部署，需要另外檢查託管平台的紀錄、流量與存取政策。

分享截圖與匯出前先核對內容，不放 API Key 或帳戶資訊。範本靈感與功能重製邊界見[來源說明](source.md)。
