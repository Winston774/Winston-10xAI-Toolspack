# 2026-W39：Jev 決策遊樂場 — 看見 AI 如何選擇下一步

同一個方塊，有人想先活下來、有人想整理空洞、有人想立刻消行。這個範本把不同目標的提案放在同一張畫面上，讓你逐步觀察「感知 → 提案 → 裁判與教練 → 落子」。

本週提供繁體中文、Apple 風格的俄羅斯方塊決策展示台。你可以直接開網頁預演，也可以下載完整的獨立程式，在本機執行與拆解。

**版本：v0.1.0 Preview。預演與自動測試已驗證；本次沒有使用有效金鑰進行真實 Jev 決策驗收。**

## 先玩一次，五分鐘看懂

1. 開啟線上展示，保持「本機預演」。
2. 選「整理殘局」，按「單步決策」。
3. 觀察五個動機的啟動情況，以及各自提出的落點。
4. 看裁判選了哪個提案、教練是否否決其他提案，再看方塊落下。
5. 展開「查看決策紀錄」，需要留存時按「匯出 JSON」。

預演使用確定性啟發式規則，API 請求數為 0。畫面上的預演百分比由規則換算，不能拿來表示 Jev 信心或勝率。同一起始情境與 seed 可重現相同決策。

## 本機開始

需要 Node.js 20.3 以上；本次測試使用 Node.js 24.12.0。沒有第三方 npm 依賴，也不需要填金鑰即可預演。

1. 解壓縮 ZIP。
2. 開啟 `completed/jev-playground/`。
3. Windows 雙擊 `start.cmd`，保留出現的服務視窗。
4. 用瀏覽器開啟 [http://127.0.0.1:4321](http://127.0.0.1:4321)。
5. 使用完畢，在服務視窗按 Ctrl+C 關閉。

macOS／Linux 或習慣終端機的使用者，在程式資料夾執行 `npm start`。也可請 Agent：「檢查 Node.js 版本，執行這個資料夾的 npm start，提供本機網址；先不要使用 API Key。」

建置會產生本機 dist 資料夾。不要直接雙擊 index.html，也不要把整個專案資料夾用一般靜態伺服器公開。

## 切換 Jev 即時模式

1. 使用你自己的 [TypeSafe 帳號](https://console.typesafe.ai/login)取得可使用 Jev 的 API Key。
2. 在「連線設定」貼上金鑰，按「僅本次使用」。
3. 切到「Jev 即時」，先做一輪單步決策。
4. 核對模式、API 請求、落子與匯出紀錄；使用完畢按「清除金鑰」。

每次完整即時決策送出 3 批請求；每批可有多題。用量由填入金鑰的帳戶負擔。已送出的請求即使暫停也可能產生用量，這個範本沒有內建金額上限，請先單步測試並確認帳戶限制。

金鑰暫留分頁記憶體，即時請求會經同源轉送服務送到 TypeSafe。清除、離頁或重新整理會清除應用程式持有的金鑰；應用程式不做持久儲存。平台與供應商的基礎設施政策另由各服務管理。詳見[隱私與資料流](docs/privacy-and-content-rights.md)。

## 程式與 Jev 各自負責什麼？

| 部分 | 工作 |
| --- | --- |
| 遊戲引擎 | 維護 20×10 棋盤、方塊序列、碰撞與合法直落位置，試算各落點結果 |
| 感知層 | 判斷生存、整地、堆疊、消行、旋轉機會是否值得啟動 |
| 提案層 | 活躍動機各自選一個合法落點；程式保留本機基準提案 |
| 判定層 | 裁判比較提案，教練分別判斷是否否決 |
| 執行與紀錄 | 從未否決提案中選擇，核對棋盤版本，落子並記錄結果 |

Jev 接收結構化 JSON，內容包含棋盤、目前方塊、接下來 5 個方塊、分數、消行數、棋盤特徵與各候選落點的預計結果。這套流程可用來學習如何把狀態、選項、判斷與執行拆開。

## 本週成果與通過標準

完成 120 分鐘的[講義與練習](lesson.md)，交出一段自己的決策解讀：

- [ ] 本機或線上預演可單步落子，API 請求數維持 0。
- [ ] 能指出至少兩個動機的落點與取捨。
- [ ] 能區分提案數與獨特落點數；多個動機可以提出同一位置。
- [ ] 匯出一份 JSON，找出三個階段、棋盤版本與最終選擇。
- [ ] 說明預演與 Jev 即時的差異，沒有把預演成績當成模型成績。
- [ ] 如有做即時測試，清楚記錄實際呼叫與失敗情況；沒有金鑰可略過。
- [ ] 分享前移除不必要的帳戶資訊，不公開 API Key。

## 限制與重試

僅支援在棋盤上方選旋轉與欄位後直接落下；未包含 hold、途中側滑、SRS 牆踢或完整 T-spin 計分。所有提案遭否決時，程式會明示採用本機基準備援。API 錯誤則暫停，不會自動切換預演。

無法啟動、金鑰失效或出現 502，先看[疑難排解](docs/troubleshooting.md)。本次驗證涵蓋 11 項離線測試與公開／本機預演操作；完整範圍見[驗證紀錄](docs/verification.md)。
