# 時間軸框選與群組編輯

## 使用方式

主影片 V1 正下方的「原音波形」顯示各片段來源音訊的強弱與停頓。點擊或拖拉波形會選取對應影片並移動播放頭，可接著按 S 分割或使用 Q／W 修剪。波形隨裁切、變速、移動、刪除與復原保持對齊；音訊 A1 保留給另外加入的音訊素材。

波形顯示原始音訊峰值，採全域一致的平方根顯示比例以提高小音量的可讀性；不逐片段正規化。片段靜音時波形呈灰色，無音軌顯示「無音軌」。音量、淡入淡出與輸出處理不改變原音參考波形。

可見區間透過 `GET /api/projects/{project_id}/media/{media_id}/peaks?chunk=0` 載入。每塊 30 秒、每 10 毫秒記錄雙聲道絕對峰值，解碼保留 48 kHz 頻寬；快取存於資料目錄的 `work/waveforms/`，不增加專案版本或復原紀錄。前端只配置可見寬度的 Canvas，最多保留 128 塊已載入資料。既有素材按需產生，無需重新匯入，超過 30 分鐘的素材也能讀取後續區間。載入中與錯誤會明確顯示，尚未取得的區間留白。

| 操作 | 手勢 |
| --- | --- |
| 移動播放位置 | 在任一軌道的空白處按住拖拉，或拖拉播放線的任一高度 |
| 框選複數片段 | 開啟工具列「框選」，從軌道空白處拉出矩形；也可按住 Shift 暫時框選 |
| 增減選取 | Ctrl／Command／Shift 點選片段；Ctrl／Command 框選可保留原本選取 |
| 整組移動 | 拖拉已選片段的中間；保留各片段間距和所屬軌道 |
| 整組刪除 | Delete、工具列垃圾桶，或右側「刪除 N 個片段」 |
| 復原 | Ctrl／Command + Z；群組移動或刪除各算一次操作 |
| 取消 | 拖拉中按 Escape 取消手勢；平時按 Escape 清除選取 |

片段邊緣仍用於單段修剪。分割與複製需選取單一片段。框選涵蓋影片、疊加畫面與音訊片段；字幕及文字保留原有操作。

勾選「連動刪除」會刪去選取片段涵蓋的時間區間，並連動所有軌道、字幕及文字。重疊區間只計算一次。

## Agent / API

沿用 `editor_edit`，帶入 `project_id`、`expected_version` 及以下 action / params：

```json
{"action":"clip_move_many","params":{"clip_ids":["clip-a","clip-b"],"delta":1.5}}
```

```json
{"action":"clip_delete_many","params":{"clip_ids":["clip-a","clip-b"],"ripple":false}}
```

每次請求只有一次版本變更與復原紀錄。後端先確認全部 ID 存在且不重複，整組移動不可超過時間軸起點；錯誤與版本衝突不會部分套用。

前端選取與拖曳預覽維持在本機，放開滑鼠才送出一次編輯請求。`timeline-gestures.js` 負責矩形交集、整組邊界及吸附計算；`Timeline` 管理手勢生命週期；後端管理原子編輯和歷史紀錄。

## 驗證

- `tests/timeline_gestures.test.mjs`：反向框選、局部交集、整組起點限制、變速片段吸附。
- `tests/test_local_editor_multiselect.py`：跨軌群組移動、刪除與單次復原、連動區間合併、錯誤和版本衝突的原子性。
- 實機驗收：使用獨立合成素材專案，框選兩段、整組拖動、Delete 刪除、Ctrl + Z 還原，並從音訊軌道與下方播放線拖拉播放位置。
