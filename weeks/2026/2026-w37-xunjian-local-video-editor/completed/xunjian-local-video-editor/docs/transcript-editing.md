# 字幕剪輯與片段剪貼

字幕面板、預覽與匯出使用相同的時間軸映射。刪除或修剪影片後，只顯示目前保留片段中的字幕；來源字幕保留供復原與其他片段使用。同一份素材出現多次時，每次出現都有獨立的字幕列與時間。

## 操作

- 點選字幕文字或該句時間，播放頭與時間軸可視範圍會跳到該句開頭；可繼續反白選字。
- S 在播放頭所在的主影片片段內分割，無需選取片段；先前的單選或多選不影響目標。
- Q 刪除目前片段從開頭到播放頭的部分；W 刪除播放頭到目前片段結尾的部分。兩者依「連動刪除」設定同步前移各軌，關閉時保留空隙。每次操作可一次復原。
- 按住時間軸播放頭或尺規拖曳時，Q／W 剪輯後仍保持拖曳；後續移動從剪輯後的位置接續計算。放開滑鼠、按 Esc、視窗失焦或切換專案才結束拖曳。
- S／Q／W 可在時間軸與字幕閱讀欄使用；輸入搜尋、校正字幕、屬性數值或開啟視窗時不會觸發。播放頭在空隙或片段邊界時不修改內容。

- 選取字幕文字，按 Delete／Backspace 或「剪除選取文字」，同步剪除對應影片並前移後方各軌。
- 「剪除此句」剪除目前這次出現的整句。其他複製片段保留原句。
- 確認視窗可勾選「之後不要再跳出這個視窗」。偏好保存在目前瀏覽器，重新整理後仍有效；字幕面板提供恢復確認視窗的按鈕。
- 每次剪除可用 Ctrl＋Z 一次復原。修改錯字與來源時間請使用「校正」。
- 選取一或多個影片片段，點「複製片段」或 Ctrl＋C，再移動播放頭並 Ctrl＋V／點「貼上片段」。貼上會在播放頭插入整組片段所需的空間，後方各軌同步後移，跨越插入位置的片段會分割。
- 片段剪貼簿限同一專案、目前頁面工作階段，重新整理後清空；輸入欄位仍保留原本的文字複製貼上。

## 時間精度

選字剪輯需要有效的詞級時間。多字詞內的單字切點依詞長均分估算，並非音素對齊；剪後應播放確認。缺少詞級時間、時間已失效或選中零長度文字時，會顯示原因並保持專案不變，仍可剪除整句。

## Agent API

使用既有 `editor_edit`，帶入 `project_id` 與 `expected_version`：

- `caption_cut`：`caption_id`、`clip_id`、目前映射後的 `text`；選字時加 `selection: {start, end}`，索引為 Unicode code point，end 不包含在內。不帶 selection 表示整句。
- `clip_paste`：`at` 為時間軸秒數，`clips` 為不帶 ID 的片段快照；保留組內相對位置與軌道。整組貼上共用一次歷史紀錄。
- `clip_trim_at`：`clip_id`、`at`、`side: "before" | "after"`，以及 `ripple`（預設 true）。切點必須位於片段內部，支援變速片段與一次復原。

文字與版本檢查可防止 Agent 使用舊字幕剪到不同內容。前端與 Agent 共用相同核心剪輯動作。
