Read the job format preset before designing graphics. Only step 3 changes materially between the format variants:

- `short-explainer`: top-half cards.
- `short-tiktok-raw`: one hook card, then raw footage.
- `long-form-youtube`: glass UI callouts and zooms.

Write `graphics-plan.json` before rendering. Graphics should clarify spoken beats, not decorate every sentence.
