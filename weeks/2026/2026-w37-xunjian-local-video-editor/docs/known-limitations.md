# 已知限制與 Stable Gate

## Preview 的意義

`v0.2.0` 可啟動本機工作台、建立空白專案、執行核心回歸與提供 25 個 MCP 工具。它尚未完成所有環境與內容型驗收，因此保持 `Preview`。

## 已知界線

- 沒有 Windows 安裝包、自動更新、依賴鎖檔或完整跨平台支援承諾。
- 本包不含模型、FFmpeg、測試媒體、使用者專案、SQLite 或匯出影片；每台電腦都必須重新驗證自己的媒體與硬體環境。
- 結構驗證、抽樣影格與短音訊證據可以指出需要審閱的地方，不能證明全片的畫面語意、口條自然、字幕正確或逐切點無黑閃。
- 本輪只完成隔離資料目錄的首頁、建立專案及空白工作台瀏覽器驗證。沒有以真人長片完成連續聲畫審閱，也沒有把正式 MP4 匯出當作已驗證成果。
- `editor_transcribe` 依賴本機模型、硬體與環境。字幕對齊顯示 `valid` 僅代表結構契約仍成立，不代表文字內容已人工校正。
- 真實 Codex／Claude Code 宿主連線應在每台學員電腦再次確認；本輪未用實際宿主完成端到端寫入流程。
- `agent_video_editor/`、`seedance/` 和 `.env.example` 是來源快照的一部分，屬於選用的歷史產品線，並非本週課程承諾。

## 需要特別避開的舊腳本

來源保留的 `scripts/prune.ps1` 與 `scripts/prune.sh` 會根據呼叫者提供的 Job 路徑遞迴刪除暫存項目。本週教學不使用它們。除非先加入並驗證「解析後路徑只能位於指定專案暫存根目錄」的保護，請不要在自己的資料上執行這些腳本。

## 升級 Stable 前的驗收項目

```text
Stable gate
├─ 重現性
│  ├─ Windows 乾淨環境安裝與啟動
│  ├─ 明確鎖定或相容矩陣化外部依賴
│  └─ FFmpeg、ASR、GPU/CPU 路徑驗收
├─ 真實媒體品質
│  ├─ 授權素材的端到端匯入、剪輯、字幕與匯出
│  ├─ 連續聲畫、字幕與逐切點候選人工審閱
│  └─ 匯出後解碼、播放與結果保存檢查
├─ MCP 宿主
│  ├─ 真實 Codex／Claude Code 連線
│  ├─ proposal / stale / undo / review 流程
│  └─ 媒體證據在宿主端的呈現與權限邊界
└─ 發布衛生
   ├─ 不含私人素材、Token、模型與快取的 ZIP 再檢查
   └─ 清楚記錄第三方依賴與內容權利
```
