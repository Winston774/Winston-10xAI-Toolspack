# 隱私、外部傳輸與內容權利

## 預設資料路徑

迅剪核心工作台預設以 `127.0.0.1` 提供服務，前端只呼叫同源 `/api`。專案、素材副本、SQLite、工作紀錄、模型、證據與匯出會留在你選擇的本機資料目錄；預設啟動腳本使用 `.local-editor/`。

這個設計降低素材被自動傳出的機會，仍不代表所有功能都永遠離線。你應把本機資料夾視為可能含有私密影片、聲音、字幕、檔案路徑與專案歷史的內容。

## 何時會接觸外部服務

| 功能 | 是否本週必做 | 何時可能外傳／下載 | 操作原則 |
|---|---|---|---|
| 核心工作台、時間軸、字幕編輯、MCP | 是 | 預設不需外部 AI API | 使用自己的本機素材，服務保持 localhost。 |
| 本機 ASR 模型設定 | 選用 | 首次執行模型設定腳本時，從模型庫下載模型 | 先確認模型授權、網路與磁碟空間；模型快取後的辨識以本機運算為目標。 |
| KIE Seedance | 否 | 你設定 KIE API Key 並明確執行 `seedance` 指令時 | 先讀服務條款、費用與內容政策；真實 `.env` 永不放入本包或 Git。 |
| YouTube 字幕／下載工具 | 否 | 你明確執行舊 `agent-video` 相關功能時 | 先確認平台規則、來源與再利用權利。 |

本包沒有任何真實 `.env`、Cookie、Token、模型、影片、音訊、SQLite 專案、匯出檔或瀏覽器驗證資料。`.env.example` 只是舊 Seedance 模組的變數範例，不能當成可直接使用的帳密檔。

## 內容權利

- 只匯入你擁有或獲准剪輯、轉錄、輸出與分享的素材。
- 字幕、逐字稿、聲音、人物肖像與螢幕錄製也可能受到合約、個資、著作權或肖像權限制。
- `references/XeTAlZiIWHE.caption-summary.json` 保留的是公開來源的摘要性參考資料，沒有完整逐字稿；它不授與原影片、字幕或轉錄內容的再散布權。
- 截圖、Issue、作業成果與 Demo 前，先刪除真實檔案路徑、客戶名稱、人物、字幕內容及任何 API Key。
