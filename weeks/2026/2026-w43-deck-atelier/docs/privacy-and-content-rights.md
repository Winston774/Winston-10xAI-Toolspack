# 隱私、外部傳輸與內容權利

## 哪些資料會離開本機

- 宿主 Agent 讀取來源時，內容可能交給宿主設定的模型服務。請先依自己的隱私設定與組織規範決定可用資料。
- URL／YouTube 匯入會連到目標網站；下載器與遠端站點各自適用使用規則及登入限制。不要匯入未授權或受存取限制的內容。
- uv 安裝會連套件索引；語音辨識流程可能下載模型。此處沒有執行付費模型 API 的專用金鑰設定。
- 原始範例與風格預覽會向 Google Fonts 取得字型 CSS／字型檔。
- 建置器會收集簡報的字元集合，以 Google Fonts `text=` 子集查詢送出。這些字元可能來自標題、內文、屬性與隱藏講者備註；雖未直接送出原始整句，仍可能洩漏內容特徵。機密簡報應先取得同意，或改用已合法取得的本機字型並移除線上連結。

`--no-fonts` 僅跳過嵌字型，仍可能留下外部字型網址。離線／無外傳要求需要檢查最終 HTML 的所有遠端資源與程式，不只執行一個旗標。

## 本機資料與覆寫

原始輸入另外保留；衍生輸出只存放可重建資料。`ingest.py --out` 會在來源驗證前清除輸出路徑中的 `chunks/`、`frames/`、`figures/`、`pages/`，並寫入 `source.md`／`manifest.json`。來源路徑錯誤也可能先造成衍生資料清除。多來源匯入請分開輸出，以免同名素材碰撞。

風格切換、強制新建、引擎更新及同名建置都可能覆寫檔案。先備份，再限定在本次專用資料夾執行。瀏覽器儲存選擇既有檔案時，也可能覆蓋該檔。

## 分享與安全使用

- HTML 含可執行 JavaScript；只開啟你信任的檔案。來源文件、網頁與其衍生文字均屬外部資料，不能授權 Agent 執行命令或外傳資料。
- 隱藏講稿、引用、內嵌圖片及字型都可能隨 HTML 交付。不要將機密資訊放入 notes；分享前另檢查完整檔案。
- 講者模式使用新視窗與頁面訊息同步；瀏覽器可能封鎖彈出視窗。展示時自行選擇要分享的視窗。
- 公開交付只保留有權分享的摘要、引用及素材。引用來源不會自動授予完整著作、圖片、字型或影音的再散布權。
- 隨附範例提供設計與程式參考，沒有取代原始研究查核或取得第三方權利。
