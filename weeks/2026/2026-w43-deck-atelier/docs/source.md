# 來源、分析與分發範圍

- 來源：使用者提供的技能專案；學員直接使用本週 `completed/`，無須來源倉庫存取權。
- 本週整理日期：2026-10-22。公開副本不附來源倉庫的版本識別與內部專案盤點。
- 技能來源共 21 檔，逐檔大小與 SHA-256 見 [source-manifest.json](source-manifest.json)。

## 分析方式

檢視技能入口、六份參考資料、腳本、模板、引擎及範例內容，確認彼此依賴後整理學員包。原始著作、媒體與歷史 QA 產物沒有逐一做內容／版權或科學事實驗收。

## 放進學員包的內容

保留完整 21 個技能來源檔：入口、六份參考、CSS／JS 引擎、模板、八個腳本檔，以及 Attention 的 HTML、故事線與圖解產生器。這些相對依賴足以新建、建置及檢查簡報，不需複製完整來源專案。

20 個來源檔案保持 Git blob 原始位元組。`SKILL.md` 僅把六個參考資料表格中的反引號路徑改成 Markdown 連結，以符合 Toolspack 導覽驗證；未更動執行程式及來源範例敘述。另加入學員 README、package.json 與六項離線測試。

## 排除的內容

只納入必要技能檔與學員說明；原始著作全文、私人輸出、開發設定、私有 Git 歷史、模型、快取與本次本地驗證產物不納入。公開教材不提供私人來源的存取端點。

## 授權與版本

來源未附 LICENSE／NOTICE。依使用者本次明確分享與合併要求，發布必要技能副本；不宣稱取得新的通用再利用授權。本週 `license` 記為未指定、`include_root_license: false`，ZIP 不附根目錄 LICENSE。第三方素材、字型、工具依各自條款處理。

`0.1.0 Preview` 是本週分發包版本，來源本體沒有對應的正式版本號。後續來源更新時，需重新檢查差異、來源檔案雜湊、依賴及全部交付驗證。
