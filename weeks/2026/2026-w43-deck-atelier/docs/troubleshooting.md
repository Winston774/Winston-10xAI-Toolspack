# 疑難排解與重試

| 現象 | 檢查與處理 |
|---|---|
| Agent 找不到技能 | 確認路徑為 `deck-atelier/SKILL.md`，沒有多包一層資料夾；整包複製後重新開工作階段 |
| `WebSocket is not defined` | 使用 Node.js 22+，建議 24；確認宿主找到的 Node 版本 |
| 找不到 Chrome | 將 CHROME_PATH 設為實際 Chrome／Edge 執行檔；Windows Edge 通常需要手動指定 |
| 分詞出現 UTF-16／stdin 編碼錯誤 | PowerShell 先設定 `$env:PYTHONUTF8='1'`；確認 uv 使用的是可正常執行的 Python |
| uv／Python 路徑失效 | 檢查目前帳號的安裝與 PATH，使用有效執行檔；不要直接沿用別台電腦的絕對路徑 |
| 輸入不存在且衍生資料消失 | 匯入器會先清除部分輸出子目錄。從原始資料／備份重建，下一次用新的專用輸出位置 |
| 舊簡報無法重新新建 | 預設拒絕覆寫；改用新目錄。確定要取代且有備份後才考慮 `--force` |
| 換風格後字溢出 | 改短標題、調整版型，重新建置並做全頁截圖；字型不同會改變寬度 |
| 字型未載入、離線變樣 | 閱讀建置警告與字型狀態；允許下載後重新嵌入，或使用合法本機字型並移除遠端連結 |
| 圖片缺失 | 檢查相對路徑、檔名大小寫與資源位置；建置器可能警告後仍產出檔案 |
| `--check` 成功卻有問題 | 讀取 JSON 的每頁 issues、字型狀態；修正後重跑，不能只看結束碼 |
| 逐步截圖都一樣 | 選擇含 step 的頁面，並加入 `--motion on`；靜態版預設顯示完整內容 |
| 按 S 沒有講者視窗 | 檢查彈出視窗權限；只允許你信任的簡報 |
| 修改後關閉就不見 | 編輯狀態只在記憶體中；Ctrl+S 後確認檔案選擇器／下載位置，重開剛儲存的檔案 |
| 建置後仍是舊內容 | 確認修改的是來源檔，重新建置；核對開啟的是新輸出檔 |

將錯誤訊息、工具版本、輸入類型及可公開的最小範例記錄下來。分享 Issue 前移除來源全文、私人路徑、敏感講稿與金鑰。反覆失敗時先退回 Markdown → 單一風格 → 靜態版的最小流程。
