# Preview 範圍與已知限制

1. 本週為 HTML 簡報技能；未提供 PPTX 匯出、多人即時協作、雲端託管或一鍵發布。
2. 故事線與事實品質取決於來源及 Agent 判斷。自動匯入與漂亮版型無法證明敘述正確；原始 Attention 範例亦未由本週重新事實查核。
3. 本機已驗證 Markdown 匯入、建置／分詞／嵌字型、瀏覽器截圖與 PDF。PDF／EPUB／Office／URL／影音實際匯入、字幕優先順序及 ASR 模型未逐項端到端驗證。
4. 十種風格只抽驗範例前兩頁；未宣稱全部 15 頁在全部風格都通過溢出檢查。每次切換都應重跑全頁 QA。
5. 1920×1080 舞台適合 16:9 簡報；手機直式、各種投影設備、所有瀏覽器與作業系統仍須另測。
6. 完整離線依賴字型與素材成功內嵌。建置器遇到外部字型或本機素材問題可能只警告後繼續；`--no-fonts` 通常仍保留線上字型。
7. 本次 Attention 建置出現 `missing asset %23n`，對應內嵌 SVG 的片段參照。15 頁瀏覽器檢查未發現相關版面問題，已抽看轉場與圖解；此警告仍保留，其他缺檔警告不可一律忽略。
8. `snapshot --check` 印出診斷 JSON，但有版面問題時未保證以非零結束碼回報。需逐頁閱讀 `issues` 與字型載入狀態。
9. 瀏覽器編輯儲存會詢問位置或下載副本。沒有固定控制代碼的自動回存；未在本次驗證中人工操作真實存檔選擇器、全螢幕或講者雙視窗。
10. Node.js 22+ 為本週建議門檻；來源部分文字仍提到 Node 18，但截圖腳本使用全域 WebSocket。Windows 中文分詞請啟用 `PYTHONUTF8=1`。
11. 人類首次安裝／宿主技能觸發、實際課堂投影與講述可用性未完成驗收，因此維持 Preview。
