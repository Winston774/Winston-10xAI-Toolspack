# 版本紀錄

版本採用 `MAJOR.MINOR.PATCH` 格式。`0.x` 階段的介面與行為仍可能調整。

## 0.1.0 — 2026-11-05

第一個公開的開蓋版 Air Mouse，沿用 Winston 與 Claude Code 協作完成的第一版應用程式。

### 功能

- macOS 選單列 App，以充電盒內 AirPods 的動作資料控制游標。
- 左右轉動、上下抬動、點按左鍵與連續點按雙擊。
- 左右耳分別保存方向校正，提供點按校正測試與靈敏度設定。
- 游標速度、上下反轉、點按開關，以及 `⌃⌥M` 暫停／恢復。
- 資料過期停止移動、動作串流恢復與可選的藍牙自動重連。
- 本機 JSONL 診斷記錄與可選原始樣本記錄。

### 公開發行

- MIT 授權、繁體中文與英文首頁、操作／架構／隱私／相容性文件。
- 可攜式建置、ad-hoc 簽章的 Apple Silicon 安裝包與 SHA-256 校驗檔。
- GitHub 建置檢查、手動發布流程、問題與 Pull Request 範本。

### 範圍

此版以開蓋使用為範圍。合蓋尚無可靠重現流程；其他耳機型號、Intel Mac、長時間穩定性與廣泛應用程式相容性尚未完整驗證。尚未提供右鍵、捲動或獨立拖放手勢。建置驗證與歷史硬體觀察詳見[驗證紀錄](docs/verification.md)及[相容性紀錄](docs/compatibility.md)。
