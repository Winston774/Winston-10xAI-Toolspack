# 相容性與研究邊界

[返回首頁](../README.md)

v0.1.0 提供兩耳留在充電盒、保持開蓋的空中滑鼠流程。是否能收到資料會受到耳機型號、韌體、macOS、連線狀態與設定影響。

## 發佈目標與已知測試組合

| 項目 | 範圍 |
| --- | --- |
| 發佈架構 | Apple Silicon / arm64；沒有 Intel 或 Universal 發佈檔 |
| 最低系統版本 | macOS 14.0，為建置設定 |
| 歷史實機系統 | macOS 27.0.1 |
| 歷史實機耳機 | AirPods Pro 第一代，型號 A2084 |
| 耳機／充電殼韌體 | 6F21 / 1.4.1 |
| 操作條件 | 原廠充電盒、兩耳入盒、盒蓋打開、自動耳朵偵測關閉 |
| 其他 AirPods 型號 | 尚無本專案可據以保證相容的實測 |

macOS 14+ 的編譯目標不等同每個版本均完成實機測試。支援 CoreMotion 耳機資料的型號，也不自動代表能在盒內以本專案流程使用。

## 已有的歷史證據

2026-11-05 的開蓋研究，在關閉自動耳朵偵測後，兩個各 20 秒的正式測量窗口分別取得 1,002 與 1,000 筆新樣本，約 50 Hz。這支持該裝置、設定與短時間窗口的可行性；尚未建立長時間穩定性或跨型號保證。

初期研究也曾在使用者確認原廠盒完全合蓋、無線的狀態下，啟動約 34 秒後取得約 91 秒的新動作串流。後續串流中斷，後來的冷啟動與入盒順序重現測試未建立穩定可重複的結果。零值 A2DP 與 HFP 通話輸入實驗也未達成可靠合蓋使用。

因此本版要求保持開蓋；合蓋啟動、持續使用與斷線恢復仍屬研究問題。現有結果不足以對所有裝置與軟體方法下全面可行或不可行的結論。

上述為公開前研究的摘要，與本次發佈產物的編譯、簽章、封裝檢查分開。私人原始記錄及研究工具未隨公開版本發佈；本輪具體檢查與限制見[驗證說明](verification.md)。

## 使用限制

- **需要開蓋與關閉自動耳朵偵測。** 合蓋可能停止動作資料或斷開藍牙。
- **重連為嘗試機制。** 開蓋後恢復成功率、不同裝置交接及睡眠喚醒仍待更多測試。必要時可在 macOS 藍牙設定手動連線。
- **音訊使用可能影響串流。** 歷史通話輸入測試曾使開蓋動作資料停止，結束輸入後恢復；其他通話、鈴聲與音訊路由情境尚未全面覆蓋。
- **每耳方向需校正。** 串流來源換耳時，尚未校正的耳機需要完成校正才能正常控制。現行設定只依左／右來源保存，換另一副耳機需重新校正。
- **點按需先停穩。** 持握、力道、耳機型號與晃動會影響判斷；個人校正測試僅反映當輪樣本。樣本不足或中途斷線仍可能產生建議值，需重測；雙擊重算結果未保證 OS 或目標 App 實際收到雙擊。
- **自動重連依裝置名稱篩選。** 已配對裝置名稱需含 `AirPods`；有多副 AirPods 時，會優先使用記住的位址，否則採最近存取者，可能需要手動確認。
- **避免同時執行其他動作感測 App。** 多個消費者可能互相影響，特別是開發用的 AirPods 動作測試工具。
- **功能範圍有限。** 目前提供移動、左鍵與雙擊；未提供右鍵、捲動或獨立拖放手勢。

## 尚待驗證

- 其他 AirPods 型號與韌體組合。
- macOS 14 至本次實機版本之間各系統版本。
- Intel 建置與執行。
- 長時間使用、耗電、反覆重連、睡眠喚醒與多裝置交接。
- 不同持握方式與使用者的點按可靠性。
- 多螢幕配置、全螢幕應用程式與廣泛第三方 App 相容性。
- 新帳號或另一台 Mac 上下載、授權與 Gatekeeper 的完整首次安裝流程。

如果願意補充相容性結果，請依[貢獻指南](../CONTRIBUTING.md) 附上硬體、韌體、macOS、設定、操作步驟及實際觀察時間。短暫收到資料與長時間可靠控制，請分開描述。
