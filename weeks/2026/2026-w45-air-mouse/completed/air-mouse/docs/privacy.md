# 隱私與資料保存

[返回首頁](../README.md)

本說明適用於本倉庫 v0.1.0 的 Air Mouse 原始碼與由它建置的 App。

## 本機處理

Air Mouse 透過 macOS CoreMotion 讀取 AirPods 的角速度、重力、使用者加速度、樣本時間與來源耳，並在本機轉成游標移動與點擊。原始碼沒有外部網路請求、雲端帳號、廣告、遙測上傳、自動更新或麥克風存取，也不錄製音訊、相機或螢幕內容。

App 會讀取目前游標位置與螢幕邊界以移動游標，註冊 `⌃⌥M` 全域快捷鍵，並發送合成滑鼠事件。它沒有一般鍵盤輸入側錄或前景 App 內容收集功能。

藍牙重連會讀取已配對裝置的名稱、位址、最近存取時間與連線狀態，找出名稱包含 `AirPods` 的候選裝置。這些操作經由 macOS 藍牙框架完成。

## 權限

| 權限 | 使用方式 |
| --- | --- |
| 動作與健身 | 讀取耳機動作串流 |
| 藍牙 | 查找已配對 AirPods，依設定嘗試重連 |
| 輔助使用 | 移動系統游標與發送點擊 |

使用者可在「系統設定 → 隱私權與安全性」檢查或撤銷權限。App 未宣告麥克風存取用途，沒有音訊輸入實作。

## 保存的偏好

UserDefaults 網域 `local.winston.airpods-air-mouse` 保存：

- 游標速度、上下反轉與點按開關。
- 點按門檻及是否來自個人校正測試。
- 自動重連開關。
- 左右來源耳的方向校正向量。
- 優先重連的藍牙裝置位址（`preferredAddress`）。

藍牙位址只保存在本機偏好，現行記錄程式不把它直接寫入 JSONL。不要將整份偏好匯出檔直接貼到公開 Issue。

## 預設記錄

每次啟動自動建立 `airmouse-<時間>.jsonl`，預設位置為 `~/Library/Logs/AirPodsAirMouse`，也可由命令列指定。App 目前沒有關閉所有記錄的介面、容量上限或自動清理功能。

| 內容 | 例子 |
| --- | --- |
| 時間與環境 | 事件時間、macOS 與 App 版本、動作授權及輔助使用狀態 |
| 串流與連線 | 啟動原因、來源耳、斷線與恢復、重連結果與耗時 |
| 設定與校正 | 部分設定變更、方向校正向量、失敗原因 |
| 點按 | 尖峰特徵、偵測或實際點擊事件、點按測試結果與提示時間 |
| 統計 | 樣本數、頻率、最大間隔、中斷次數、點擊數與工作階段摘要 |

預設記錄會包含部分衍生的動作特徵。加上 `--raw` 後，另有逐筆樣本時間、來源耳、角速度、重力、加速度，以及部分情況下的投影軸值。詳細模式會快速增加檔案大小，也提供更細的動作時間線。

App 使用一般本機檔案與系統偏好保存資料，未另外加密；存取受 macOS 帳號、檔案權限與磁碟加密設定影響。若使用者將記錄資料夾設在同步磁碟或雲端資料夾，該服務可能依自己的設定同步檔案。

## 暫停、結束與刪除

`⌃⌥M` 暫停的是游標控制。暫停期間仍讀取動作、偵測資料與寫入記錄；新的自動藍牙重連嘗試會被停用，已送出的請求可能仍會完成。選單「結束」才會停止 App 與動作訂閱。

刪除 App 不會自動刪除記錄與偏好。可在結束 App 後：

1. 從 Finder 刪除 `~/Library/Logs/AirPodsAirMouse` 中不需要的檔案；自訂路徑需另行清除。
2. 如需重設設定，執行 `defaults delete local.winston.airpods-air-mouse`。這會清除校正與優先藍牙位址，保留 macOS 的裝置配對。
3. 在系統設定中撤銷 App 權限，並移除 App。
