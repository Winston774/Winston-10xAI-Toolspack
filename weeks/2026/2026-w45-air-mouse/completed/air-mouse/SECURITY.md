# 安全回報

目前接受最新公開 `0.1.x` 版本的安全問題回報。專案處於早期階段，未承諾固定支援年限或修復時限。

請使用 [GitHub 私密漏洞回報](https://github.com/Winston774/air-mouse/security/advisories/new)，提供受影響版本、重現步驟、影響及可能修正方式。請勿把尚未修復漏洞、私人資料或存取憑證貼進公開 Issue。

Air Mouse 具有輔助使用權限，能產生游標與點擊事件。請僅安裝你信任來源的版本，並核對 Release 提供的 SHA-256。公開安裝包使用 ad-hoc 簽章，尚未取得 Developer ID 簽章與 Apple 公證；簽章完整性檢查不代表 Apple 已驗證發布者。

App 的資料處理與本機保存內容見[隱私說明](docs/privacy.md)。一般連線、校正及相容性問題請使用公開 Issue，並先移除個人資訊。
