# 疑難排解

| 現象 | 建議 |
|---|---|
| App 被 macOS 阻擋 | 先確認來源與校驗碼。此版本 ad-hoc 簽章、未公證；若標示惡意內容或損毀，停止開啟並查證 |
| 沒有動作資料 | 確認耳機已連接、雙耳在盒內、保持開蓋，關閉自動耳朵偵測；檢查動作與藍牙權限 |
| 游標沒有動 | 確認輔助使用權限、完成來源耳校正，並檢查是否已暫停 |
| 換耳後方向錯誤 | 每耳分別校正；換另一副耳機也需要重新校正 |
| 點按容易誤判 | 先停穩，重新執行個人點按校正；樣本不足時結果可能不可靠 |
| 斷線後沒有恢復 | 檢查藍牙連線，必要時手動重連；自動重連效果依環境不同 |
| 擔心仍在收集資料 | 暫停仍會讀取及寫記錄；從選單結束 App 才停止 |

完整步驟見[來源使用指南](../completed/air-mouse/docs/usage.zh-TW.md)。回報前自行檢查日誌，移除藍牙位址與私人資訊。
